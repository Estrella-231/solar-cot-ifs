# 判云误清零与 GHI 退化的逐时刻核查

## 结论

误清有云像元确实存在，能解释部分时刻的 GHI 误差变化；但不能解释本次配对重训的全部退化。在有 CPP 参考的共同子集中，仅恢复误清的有云像元作用很小，恢复 CPP 判晴空位置的原 R 输出反而影响更大。另有大量时刻中心 3×3 的物理 COT 完全未改变，两个重新训练的头仍产生不同结果，说明训练后的参数和 COT 归一化变化同样不能忽略。

这不是“CPP 晴空中的非零 COT 在物理上正确”的证明。它说明：对当前 GHI 头有用的连续 R 表示，与 CPP 云分类是否正确不是同一个评价目标。云影、邻云、瞬时卫星与 15 分钟地面平均的支持差异，以及参考产品误差，仍是未分清的物理解释。

## 数据与方法

- 使用 2026-10-15 完成的 seed42、30 轮 AC_raw / AC_gate 配对训练输出；四里 2,128 条、竺家 2,351 条验证记录，实际更新数分别 390、420；同站两组初始化、每轮样本顺序及更新预算一致。
- 输入为**真实目标时刻 AGRI**，不是 SimVP 外推；GHI 标签是以该目标时刻结束的 15 分钟区间均值。没有使用新 test。
- 按 `(station, target_time_utc)` 精确一对一关联保存的 GHI 输出、原/门控实际 COT bank、实际判云概率，以及 CPP CLP/COT 参考。
- 1,398 个 CPP 验证样本中，1,291 个能关联到具有有效 GHI 主标签的记录：四里 615 个、竺家 676 个，共占 GHI 验证集 28.8%。无 CPP 的记录标为未知，不当作晴空或“没有误清”。
- GHI 只读取原分辨率中心 **3×3**，对应 16×16 图上的 `[7:10,7:10]`；站点像元 `(8,8)`。16×16 外围的清零不会直接进入这个 GHI 头。
- 本文“误清云”：实际 bank 中原 R COT>0、门控后恰为 0，且同像元在共同有效支持上 CPP CLP=1/2。它包括原 R 已低于判云阈值 0.1 的像元；因此与此前云 POD 统计中的“新增漏检”不是同一个计数。
- 同一个冻结门控头、同一个门控训练集归一化，分别做：原门控输入；仅恢复 CPP 有云且被清零的像元；仅恢复 CPP 晴空且被清零的像元；恢复所有原 R。恢复的是原 R 值，**不是 CPP COT 真值**；CPP 只用于选择诊断位置。两类恢复不能因网络非线性被简单相加当作归因比例。

## 逐时刻统计

| 项目 | 四里 | 竺家 |
|---|---:|---:|
| 全 GHI 验证样本 | 2,128 | 2,351 |
| 有 CPP 参考的共同 GHI 样本 | 615 | 676 |
| 中心3×3出现误清云的时刻 | 13（8个日期） | 17（9个日期） |
| 中心3×3被清零的 CPP 有云像元数 | 38 | 56 |
| 上述像元中原 R COT≥0.1 的数量 | 14 | 2 |
| 全16×16被清零的 CPP 有云像元数 | 2,080 | 2,899 |
| 全 GHI 样本中中心3×3物理 COT 没有任何改变的时刻 | 1,666 | 1,642 |

同一个位置在不同时刻计为不同像元记录。不能把像元数当作独立事件数；13/17 个时刻也未当作独立统计重复，区间以 BJT 目标日期聚类。

## 固定门控头的恢复诊断

下表所有列均在**同一站点、同一个 CPP 共同子集、同一冻结门控头、同一归一化**上比较。单位为 GHI RMSE（W/m²），使用本次 CPU 重载的共同基线。

| 输入处理 | 四里，N=615 | 竺家，N=676 |
|---|---:|---:|
| 实际门控 COT | 146.9321 | 123.1988 |
| 仅恢复误清有云像元的原 R 值 | 146.9226 | 123.1825 |
| 相对实际门控的变化 | −0.0095 | −0.0163 |
| 仅恢复 CPP 晴空位置的原 R 值 | 146.7273 | 121.8643 |
| 相对实际门控的变化 | −0.2048 | −1.3344 |
| 恢复全部原 R 值 | 146.7184 | 121.8481 |

误清云恢复的日期配对 95% CI：四里 [−0.0450,+0.0122]，竺家 [−0.0375,−0.0016] W/m²；2,000 次日期簇 bootstrap。仅是已查看验证集上的诊断区间。

在全验证样本上，仅恢复有 CPP 证据的误清云，RMSE 改变分别是 −0.0030、−0.0054 W/m²；未覆盖 CPP 的记录保持原输入。这不能代表其余未知记录没有误清云。

原训练头 vs 门控训练头的全验证 RMSE 差仍为 +0.0766、+0.5767 W/m²；各站日期簇 95% CI 分别 [−0.0080,+0.2243]、[−0.1593,+1.3990]，均跨零。当前属于单种子小幅退化点估计，尚不能宣布稳定退化。

按逐样本平方误差差额相加，四里 11.7%、竺家 60.8% 的净新增平方误差位于**中心3×3物理 COT 完全没改变**的记录。这里是样本组的误差记账，不是物理因果贡献比例。两组使用各自训练后的权重和归一化，物理输入未改变不代表标准化输入与模型映射相同。

### 反例与选例规则

两站分别取中心3×3已确认误清云样本中，门控−原始平方误差差额最大、最小的记录，另取 CPP 支持完整、中心3×3没有任何清零记录中差额最大的记录；共6例。极端选例仅用于看机制，不用于评价总体收益。没有刻意只展示退化。

- 四里2024-04-19 14:00：局地COT完全没变，原头227.26、门控头225.54、观测629.67 W/m²。
- 竺家2024-04-20 12:00：局地COT完全没变，原头413.56、门控头382.26、观测521.33 W/m²。
- 四里2025-07-08 13:45、竺家2025-07-09 10:00：虽存在误清云，两组头的配对误差却改善。这再次表明“有误清”与“配对退化”不是一一对应。

六例完整图见 [云图与时序PDF](cloud_images_and_GHI_timeseries.pdf)，事件索引见 `selected_cases.json`，逐样本数据见 `paired_sample_diagnostics.csv`。

## 下一步

当前不值得继续仅调判云阈值，或把本轮未达标候选自动扩到seed43/44。保留原连续 R-COT 作为参照；新的候选如要使用云概率，应先考虑将其作为不确定性条件，避免直接丢掉连续值，另立控制变量方案后再训练。

优先解释“CPP 判晴空，但原 R 非零值仍被 GHI 头使用”的事件：区分邻云/云影空间关系、瞬时图与15分钟平均的时间支持差别、R或CPP误差，以及头对相关代理量的依赖。当前诊断没有确认其中哪一项是物理根因。
