# 四里 COT 轨迹诊断

仅使用区域 GHI pilot 的 128 个验证序列候选，不读取 test，不训练模型。CPP 可用性及平移在域支持限制评价覆盖；每时效四种方法使用同一像元掩膜，不填补缺测。

- maps：真实 AGRI C03/C02/C01 增强 RGB 代理、CPP、持久性、平移、SimVP→R、真实未来 AGRI→R，6 行对应上述顺序；5 列为 +15/+60/+120/+180/+240 min。青色十字为四里像元 (163,148)，显示原分辨率 64×64 邻域。
- trajectory：站点单像元随时效的 COT，无空间平均；CPP 缺失处断线。
- spacetime：穿过站点的单行 64 像元剖面随时效变化，青线为站点列；倾斜结构可表示沿该剖面的云移动，但不能代替二维运动矢量。
- sili_lead_rmse：站点像元与局地 64×64 两种支持域的误差，不能混为同一指标。

COT 色标统一 0–60，超过60标识为色标上溢；RGB按每案例所有可用未来帧的逐通道2%–98%共同拉伸，无平滑，不作为真实自然色。原始 RGB 通道及 COT 字段、mask 保存在 source.npz；拉伸参数和确定性案例选择保存在 cases.json。案例分别取 SimVP−平移的站点 RMSE 差最小、最大和中位数，要求至少8个有效站点时效，因此不是随机代表性案例。

持久性与平移的起点用同一冻结 R、实际历史输入在CPU FP32重算；历史 C13 先按原 SimVP 归一化并将无效像元设零，再做相位相关，与原基线输入处理一致。CPU重算与保存GPU历史COT存在数值差异，最大log1p差写在summary.json；这一图组是诊断数值变体，未通过逐像元CPU/GPU严格等价，不替代原GPU正式指标。oracle使用保存的真实未来AGRI→R输出，不是真实COT，不可部署。CPP生产链独立物理QA仍未闭合。

绘图脚本：scripts/plot_sili_cot_trajectories_20260927.py。v1为绘图准备过程版本，平移运动输入未恢复原合同，不用于结论；仅使用本v2目录。

2025-07-09 12:15 BJT初始化：CPP在+150至+180min呈现站点COT约61–69的厚云过程；真实未来AGRI经同一R的输出约54–65，重现过程；SimVP→R仅约7，漏掉该峰。该案例站点COT RMSE：平移19.395，SimVP30.586，oracle3.964。此例估计位移为(0,0)，平移退化为持久性，不能展示平移成功跟踪云；需要进一步评价运动估计可靠性。

四里站点像元共同有效域RMSE，依次持久性/平移/SimVP/oracle：+15min=4.11/4.17/5.79/2.79（90个站点时效样本）；+60min=6.21/6.54/6.13/2.59（80）；+120min=8.61/8.43/9.46/2.85（65）；+240min=6.59/6.72/9.82/2.14（54）。不同lead有效样本变化，不能把曲线下降直接理解为时效越远越容易。此诊断不含GHI因果归因，不由一个选择性极端案例推导总体失效率。

下一步：优先核查四里云团强度衰减与漏报过程，补充运动非零且参考云边界明确的案例，检验平移矢量/多云层/局地运动；固定SimVP情况下先明确有价值的COT轨迹目标，再决定E_region训练。保留当前反演R作为基线，但仍需按云情景检查，不能从oracle好的一例推导R已充分准确。
