# 四里厚云峰与非零运动核查（2026-09-27）

本轮检查现有128个区域GHI pilot验证序列，124个有有效站点CPP参考，总1424个站点/目标时效记录。没有训练、不读test。CPP仍是反演参考，原生产者QA未闭合。定义性诊断阈值为CPP COT>=30且预测COT<10，不能冒充通用云分类标准。

## 证据

- 63个CPP厚云站点时效记录，SimVP→R严重漏报9个，真实未来AGRI→同一R严重漏报0个。+120到+240min有39个厚云记录，其中7个严重漏报。9个漏报集中在3条序列（7月9日6个、7月30日1个、8月15日2个），这些帧不是独立事件，不能用9/63直接给总体显著性或稳定概率。
- 124个有站点参考序列中27个历史全区域C13相位相关位移非零。仅1条同时满足非零、至少8个有效站点时效、CPP峰>=30。零位移不代表实际云静止，非零也不证明速度正确；当前运动基线的可靠性须独立核验。
- 2025-07-09 12:15 BJT：+165min CPP68.747，真实未来AGRI→R64.621，SimVP→R7.391。未来峰漏失，不能把其argmax在+15min解释成同一个云峰提前150min。
- 2025-08-14 11:30 BJT：历史估计每15min行-1、列-2像元；+135min CPP67.838、真实未来AGRI→R65.770、SimVP→R32.061。SimVP序列最高值40.673出现在+15min，但参考厚云增强过程未被恢复。平移能让站点COT从约34升到48，仍低估峰值，峰附近约44。真实/预测RGB使用完全相同C03/C02/C01及共同真实图逐通道2%–98%拉伸：预测场明显平滑，厚云在站点附近的增强过程缺失。视觉线索不能独立量化所有通道误差或证明反演器对预测域没有额外偏差。

## 图与复现

- *_rgb_cot.png/pdf：真实RGB、预测RGB、CPP、预测AGRI→R、真实AGRI→R；共有5行，青十字固定四里像元(163,148)。按同一色标0–70 COT，越界在色条标识。RGB是增强代理非自然色，无平滑或新增细节。
- *_maps.png/pdf：另加持久性及恒速平移，用于对应空间结构。
- *_trajectory.png：站点单像元COT，不做空间平均。
- *_spacetime.png/pdf：穿过站点的同一行像元随时效变化，无空间平均；不能单凭剖面判定二维运动或云层高度。
- *_source.npz、selected_cases.json、sequence_catalog.json、summary.json：源字段、掩膜、拉伸参数、选择条件、逐序列和统计。两个展示案例分别按峰低估最大以及非零运动厚云条件选出，不是随机代表性样本。缺参考处空白，不填晴空。

预测与oracle使用原GHI bank保存的GPU输出。平移/持久性起点按同一冻结R及历史输入CPU FP32重算；与GPU历史log1p COT最大差分别0.01847、0.00106，严格逐像元等价未通过，平移图仅为诊断数值变体，不替代原GPU指标；9/63统计直接使用原GPU预测及CPP，不依赖CPU平移重算。

## 下一步与独立轨迹模型目标

1. 扩大冻结验证诊断覆盖，按固定日期/季节抽样，覆盖非零运动厚云、云边缘经过站点、增强和消散及相近条件正确案例。保持正式总体指标同样本，不以困难案例筛选主表。
2. 核查历史运动矢量：比较不同历史帧对及局地/区域估计，检查运动置信度，并仅作诊断地对照参考云结构后续移动。不能因移动标签会降低误差就修改标签。
3. 轨迹候选先以“区域输运+厚度演变”明确两个目标：云的二维到达位置/时间；站点附近厚云峰值、持续时间、消散过程。只移动不改变云不能满足后一目标。输入保持真实历史AGRI/COT，未来真实AGRI/CPP不进入可部署输入。
4. 未来训练时以持久性、恒速平移和固定SimVP→R为同样本基线，分别验证厚云漏报、峰幅度、空间定位/事件到达与整体误差；不要将缺峰案例argmax偏差当作到达误差。GHI增益仍需稳定训练下单独验证。现有证据不足以区分全部误差来源或选择最终网络。
