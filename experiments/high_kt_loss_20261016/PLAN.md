# 高透过情景损失配对试验

2026-10-16，用户授权选择一个有已有证据支持的改动并执行。

## 承接与唯一改动

承接 [高值低估持续问题记录](../../docs/HIGH_GHI_UNDERESTIMATION.md)。统一特征双向残差已能部分缓解低估，但COT没有稳定额外收益；三帧历史确实被使用；R太阳几何修复不能解释/消除该错误。当前输出为softplus kt，没有kt≤1硬上限，不修改输出范围或增加结构。

唯一新因素为**训练损失对高透过情景的权重**。固定训练标记 `clear >= 100 W/m² and observed interval kt >= 0.9`；该标记沿用既有高亮诊断的kt门槛，去掉R-COT条件以保持无COT/有COT完全同权。权重为该组2、其余1；按站点全训练集平均权重归一化。损失 `mean(w_normalized * ((pred_GHI - observed_GHI)/1000)^2)`，两种误差方向同等惩罚。只计算train权重，验证评分与选模仍使用原始未加权整体GHI RMSE。没有推理时真值路由、删零值、clip kt、重新选高值日期、阈值/倍数搜索。

证据支持的是“这个训练目标值得检验”，不是已证明样本频率或MSE条件均值为根因。该方案与09-10/09-28的kt损失改GHI损失不同：当前本来已用GHI MSE；与09-22的CPP厚云加权R也不同：本轮只改变GHI头训练目标。是否高值组真是少数，由冻结train计数如实报告；即使不是少数，也不据此改动事先固定的候选。

## 四组固定对照

1. `A_uniform`：三帧AGRI与共同太阳几何，原GHI MSE。
2. `A_bright2x`：与1相同，只改上述损失权重。
3. `AC_uniform`：与1相同，加入修正几何R-COT三帧空间场。
4. `AC_bright2x`：与3相同，只改上述损失权重。

沿用 `r_geometry_downstream_ghi_20261016` 的独立分站训练、3×3、T−30/T−15/T、41,665参数、train47,666/val4,263、月度划分、共同train归一化、两版R训练预测合并拟合的固定COT scaler、seed42/43/44、batch1792、30epoch、AdamW lr0.001/weight_decay0.0001、cosine eta_min0.00001、grad clip5。每站每seed四组同初始参数、同每轮样本顺序和更新数。共24次小头拟合；源模型/缓存不覆盖。与原实验的A及corrected-R AC作输出复现对照，硬件差异仅披露，不拿旧/新硬件结果当损失对照。

本轮四组均用本机已有PyTorch2.5.1和单RTX4060训练。服务器全账户已有3个未结束任务，不qsub，不在登录节点训练。先同batch前后向profile，保留显存余量；该小头不扩卡，也不为填显存而改变配对更新预算。源数据从已验收train/val缓存按固定文件名只读复制，逐文件SHA256绑定；不读取test。

## 评价与停止条件（训练前冻结）

- 保存每组/站/seed的逐样本预测、CPU重载检查、权重哈希、训练曲线；独立FP64重算RMSE、MAE、bias。
- 原高透过组、全验证、低kt(<0.3且clear≥100)、中间kt、实测GHI≥800、原高亮有云诊断组分别报告。所有分组同四组支持，不因结果删行；原可疑持续零值只加标记敏感性，不从训练或主评分去掉。
- 核心受控对比是各输入下bright2x−uniform，以及同损失下AC−A；三seed先在站内平均、再两站等权。按同一目标BJT日期配对2000次bootstrap，条件于已反复查看的验证集和选模，不声称独立test。
- **高值修复候选通过点估计条件**：高透过组RMSE下降且bias绝对值缩小；全验证RMSE不升；每站全验证RMSE退化不超过1 W/m²；低kt组两站等权RMSE退化不超过1 W/m²。逐站和种子全部披露，不能用总体抵消来隐藏失败。
- 只有高值组ΔRMSE日期区间上限<0才称本验证上方向稳定；COT额外价值须独立检查AC_bright2x−A_bright2x区间，不能用A的改善充当COT收益。
- 固定旧无权A定义低估行，报告新组上调比例和低估误差；另报各损失内AC对各自A的方向。真值仅作训练/评价。原六案例、254条失败记录只作回归检查，不用来选模或替代全验证。
- 若高值改善却整体/低值退化，登记权衡，**不替换正式模型、不增大权重、不再调阈值**。若条件未过，本轮候选关闭。即使通过也只是验证pilot，不改变test关闭状态。

本轮不改R/SimVP、空间范围、历史长度、GHI结构或论文。
