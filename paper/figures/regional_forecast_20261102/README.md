## 来源与口径

湖北来源为 `refine-logs/hubei_threeframe_dydiff_forecast_20261102/recovered/evaluation/`，湖南来源为 `refine-logs/fulltrain_forecast_cot_20261101/observed_trained_heads_evaluation_v1/`。各读取 `predictions.npz`、`keys.csv` 和 `RESULTS.json`。这是当前24,451条湖北及66,086条湖南验证记录，不是旧湖南63,480条底图对照子集。

每个站点和随机种子分别计算RMSE，再等权平均；不先平均三个种子的预测。差值定义为“加入预测COT−不加COT”，负值表示改善。每个时效的95%区间由5,000次北京时间目标日期块配对bootstrap得到（固定随机种子20261102），同一次抽样对所有方法、站点和种子使用相同日期权重。同一日期内重叠预报记录整体保留。区间是各时效的点区间，不是多时效同时置信带。

没有添加、删除或抽稀源评价记录，没有平滑。核对了时间差与时效一致、站点/初始化/目标键不重复、保存预测有限。新复算的两个总体及32个逐时效RMSE和区间，与原结果最大绝对差为1.14e-13 W/m²。test载荷未读取，无模型训练或GPU计算。

灰带仅标示+15/+30分钟的三帧输入中含已知历史图；+45分钟起三帧全部是预测图。它不是样本筛选范围。
