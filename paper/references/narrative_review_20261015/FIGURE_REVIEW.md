# 逐图调研：图型、位置与论证作用

2026-10-15。依据三篇已下载PDF的全部图注及图所在页面视觉检查，不以摘要推测图形。页码均为PDF页序。只阅读与制定方案，本轮未制作本文科学图件。参考页面阅读缩略图仅本地保存。

## 1. Chen et al. (2023), Applied Energy

[全文来源](https://www.li-realab.info/publication/solar-forecast/chen-2023-resourcing/chen-2023-resourcing.pdf)。17页PDF，正文编号Fig.1–11，共11张图；子图不另计。正文同时研究GHI和DNI，不能把其图数直接当作本项目需求。

| 图号/页 | 视觉形式与位置 | 在论证中的作用 |
|---|---|---|
| 1 / p.3 | 通栏流程图，Data and methods | 串起观测、标签和估计过程 |
| 2 / p.3 | 多波段小图矩阵，数据介绍 | 让读者看到真实输入及波段差异 |
| 3 / p.4 | 上下两个相关系数热图，相关分析 | 支持通道选择的依据 |
| 4 / p.6 | 通栏神经网络结构图，模型介绍 | 说明空间图像如何输出晴空指数 |
| 5 / p.6 | 单栏训练/验证损失曲线，方法尾部 | 展示收敛；并非最终性能主证据 |
| 6 / p.8 | 2×3逐日时间曲线，结果段 | 两站晴/云/部分有云案例，看动态误差 |
| 7 / p.9 | 2×3柱状图，GHI云况结果 | 列分天空状态，行分误差指标，站点比较 |
| 8 / p.9 | 与Fig.7一致的DNI图 | 对另一物理输出重复评价 |
| 9 / p.10 | 多站小面板散点，GHI误差分析 | 比较晴空指数区间内RMSE和偏差 |
| 10 / p.11 | 与Fig.9对应的DNI图 | 显示另一个输出的条件差异 |
| 11 / p.12 | 多站短时事件曲线，讨论附近 | 用云增强事件解释模型局限 |

可迁移：真实输入图、同一版式跨站比较、总体后按物理条件分解，再用事件解释。无需照搬：DNI整套图、与我们主张无关的通道相关热图，以及正文收敛图。其密集多站面板应按最终字号精简。

## 3. Sasaki et al. (2024), arXiv:2407.04283

[原文](https://arxiv.org/abs/2407.04283)。5页PDF，Fig.1–5共5张，整体采用紧凑单栏图；期刊长文不必照搬这种密度。

| 图号/页 | 视觉形式与位置 | 在论证中的作用 |
|---|---|---|
| 1 / p.2 | 网络与物理运算示意，§3 | 说明全天空估计结构 |
| 2 / p.3 | 有无物理约束的时间曲线，§3.2 | 紧邻方法呈现约束作用 |
| 3 / p.3 | 流程+实际中间输出，§3.3 | 展示晴空概率估计如何工作 |
| 4 / p.4 | 可见光图与估计场并排，方法末/结果前 | 真实雪地场景下辨别问题 |
| 5 / p.4 | 两个事件时间曲线，§4 | 连接模型设计与误差修正；总体比较另用表格 |

可迁移：真实图像和辐射曲线配合，比只有汇总柱图更能解释物理困难。不能把其选定案例当成充分统计证据。

## 4. 对本文的选择

三篇都采用方法说明、量化比较、条件分析或具体场景的组合，但图数和排列并不统一。本文建议7张正文图：2张交代数据与方法，4张支持同期检索/估计价值，1张检验未来应用。新增一张COT检索质量图，使“作为输入的COT是否合理”有明确位置；原计划中地图改为Fig.1，方法改为Fig.2，遵循正文首次引用顺序。

图型不能替代论证：密度散点适合分布误差，不擅长显示3%的增量；因此总体主图采用绝对误差配对点与差值区间。空间场与时间曲线用于解释机制，时效曲线用于预报，容量对照用小表即可。详细布局和删减原则见[FIGURE_PLAN.md](../../FIGURE_PLAN.md)。
