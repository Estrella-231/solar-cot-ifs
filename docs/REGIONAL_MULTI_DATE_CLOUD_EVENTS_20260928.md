# 湖南四里多日期云事件归因（2026-09-28）

本轮将单日展示扩展到跨日期验证案例。只复用固定Sili验证cohort、现有SimVP/R/COT-GHI pilot权重和保存的预测，没有训练模型、没有读取test。CPP是卫星反演参考，不是独立云物理真值。所有结论用于误差定位，不作为预报技能或论文主结果。

## 样本范围与事件筛选

从已固定的128条Sili验证序列中，124条至少有一个站点CPP有效未来目标。事件规则只看站点像元CPP COT轨迹和预先保存的历史C13运动估计；**不看GHI曲线或SimVP误差来挑本轮新增案例**。候选类别可以重叠，筛选后每类最多取两条不同BJT日期，按可用日期顺序均匀分散，并且新增类别之间不重复序列。

| 类别 | 预先固定的筛选条件 | 124条验证序列中的候选数 | 新选案例 |
|---|---|---:|---|
| 增厚增长 | 至少10个CPP有效时效；峰值COT≥30且在+75分钟或之后；+75以后峰值比最初4个时效均值高至少15 | 7 | 2025-07-28 06:15；2025-08-20 15:00 BJT |
| 消散 | 至少10个CPP有效时效；最初5个时效峰值COT≥30，且比最后4个时效均值高至少15 | 3 | 2025-07-12 06:45；2025-07-29 11:45 BJT |
| 运动代理 | 至少10个有效时效；峰值COT≥15、全轨迹变化幅度≥15；历史位移估计模长≥1像元/15分钟 | 3 | 2025-07-26 06:15；2025-08-17 15:15 BJT |
| 低COT平稳对照 | 至少12个有效时效；峰值COT<20且轨迹幅度<10 | 56 | 2025-07-04 11:00；2025-09-10 07:30 BJT |

“运动代理”仅表示历史相位相关位移不为小值，**不等于已经追踪确认同一个云对象穿过站点**。新增8例之外，图中保留先前的3个案例作为衔接锚点：2025-07-09增厚漏报、2025-08-05消散、2025-08-14厚云移动。这三个旧案例是在此前模型误差/厚云诊断中选出的，存在结果导向的选择偏差；仅作个例衔接，不纳入本轮候选频数或效果推断。最终图示共11个不同日期、11条序列。

## 图中量的含义

- AGRI使用四里站点周围64×64裁块，展示C03/C02/C01增强伪彩；所有日期与时效共用同一逐通道2%–98%拉伸，青色十字为湖南网格站点像元(163,148)。它不是自然色，也不是256×256湖南全区图。
- COT曲线是站点单像元，不做区域均值。CPP曲线为参考；`R(real future AGRI)`使用真实未来卫星图经冻结R反演，只是离线oracle诊断；`R(SimVP forecast AGRI)`是当前部署链路可用的预测图反演；`history + fixed translation`是常速度平移诊断，不包含云厚变化。
- GHI实测值与保存的pilot预测按不可变`head_row_ids`重新连接，实测标签是目标时刻结束的**15分钟区间均值**，lead为初始化后+15至+240分钟。图中没有用瞬时观测替代区间标签。
- CPP缺测和真实AGRI缺帧没有填成零或晴空。2025-08-17序列在后段缺少CPP有效时效，且真实AGRI +210至+240分钟帧缺失；2025-08-20序列有12个CPP有效时效，真实AGRI +225/+240分钟帧缺失。图中显式标注这些缺失。

## 观察边界

这些分层个例足以检验图示中的现象是否跨了不同日期，但它们是按COT轨迹特征挑出的诊断样本，且部分目标时效重复属于同一条4小时序列。不能把11条案例当作独立天气事件总体，更不能把逐时效点数当独立样本。

当前图仍显示不同误差形态并存：部分增厚过程里真实AGRI经R可恢复CPP中的厚云变化，而SimVP图反演较弱；消散案例中预测COT有时下降偏慢；有运动代理的案例并不都对应厚云事件；低COT控制也提醒GHI变化不只由站点单像元COT决定。新选的8条尚需逐例核对云对象位置、太阳几何与可用区域支持后，才能进一步拆分反演、运动和演变误差。它们不能支持“扩展后的运动场已能预测过站时间”，也不能单独证明这些COT差异造成GHI误差。
