# 分阶段 COT 分类与回归错误诊断

日期：2026-09-24  
数据：真实观测 AGRI 验证集 6,536 行、1,664,013 个有效像元；仅以 CPP COT 作为检索参考标签。未读取测试集。

## 路由诊断

“CPP 参考类别路由”是验证诊断：按 CPP COT `<0.1` 或 `>=0.1` 选择低 COT 或有云回归分支。它使用了参考标签，不能部署，也不代表现实预报表现；作用是估计分类路由错误的影响上限。回归头取自本轮已训练模型。

| 验证路由 | 近零 COT RMSE | 全部像元 RMSE | CPP COT≥0.1 RMSE | CPP COT≥30 RMSE | 站点 5×5 RMSE |
|---|---:|---:|---:|---:|---:|
| 原冻结 R | 0.7712 | 4.2462 | 5.4007 | 11.9498 | 3.9436 |
| 分类器自行路由 | 0.8251 | 4.3383 | 5.5144 | 11.6708 | 4.0462 |
| CPP 参考类别路由（oracle 诊断） | **0.0160** | 4.3020 | 5.5073 | 11.6708 | 4.0252 |

参考类别路由把近零 RMSE 从 `0.8251` 降至 `0.0160`，说明误分类确实是近零误差的主要来源。但全图 RMSE 仍高于原 R（`4.3020` 对 `4.2462`），有云像元和站点邻域也仍较差。结论是：**分类路由解释了近零子集的恶化；仅把分类做对仍不足以改善整体反演，有云回归分支也有误差。**

## 错误空间位置

图中伪彩色由原始 AGRI `C03/C02/C01` 分别作为 R/G/B，逐通道用整个验证集的固定 1–99 百分位拉伸。CPP、专家输出和预测图均为 16×16 像元；COT 色标显示范围为 0–40，低 COT 专家单独按 0–0.1 显示。白色叉号标出所选近零误判像元。

![近零误判案例：AGRI 伪彩色、CPP、分类概率、两个专家与两种路由](../results/cot_staged_diagnostic_20260924/false_cloud_case_montage.png)

案例按“CPP COT `<0.1`、模型输出 `>=10`”筛选，每行取最严重的不同验证样本。四例的误判像元 CPP COT 均为 0，模型云类概率约 `0.986–0.987`，输出 COT `32.40–36.93`。四例均为白天且太阳高度不低；其中三例位于 patch 最上边界。

在全体验证像元中，近零参考像元若紧邻至少一个 CPP 有云像元，分类为有云的比例为 `26.36%`；离 CPP 有云区至少一个像元的近零像元对应比例为 `1.84%`。这显示误判高度集中在 CPP 云边界附近。patch 外边界近零误判率是 `8.30%`，内部为 `5.18%`，有一定边界效应但差距远小于云边界差异。低 `cosSOZ<0.2` 与较高 `cosSOZ>=0.2` 的误判率分别为 `5.14%` 和 `5.93%`；低太阳高度角不是当前主要解释。夜间误判率为 0，误判发生在白天。

![云边界与太阳几何分组的近零分类误判率](../results/cot_staged_diagnostic_20260924/error_context_rates.png)

这些证据支持“模型在 CPP 云边界附近把部分 AGRI 特征判成有云”的描述，但不能单独证明 AGRI 与 CPP 地理错位。边界邻接还可能来自卫星视场/分辨率差、CPP 检索平滑或薄云处理差异。需要进一步做 16×16 patch 的 AGRI–CPP 像元配准/偏移审计，才能判断产品是否错配。

## 复现与数值边界

诊断脚本在 `zjnu-hpc` 的 `swc` 环境读取现有验证包和已保存 checkpoint，只做 CPU 前向，不提交训练作业。原 GPU 保存的分类概率用于保持原路由；两个专家分支在 CPU 重放。CPU 与 GPU 分类概率差异最大 `0.00297`、99 百分位 `0.00074`；两个回归专家重放后的最终预测差异最大 `0.1234` COT、99 百分位 `0.0198` COT。图中专家输出因而是数值重放值，不替代已保存的正式 GPU 预测。完整逐指标结果和所选行元数据见 `results/cot_staged_diagnostic_20260924/diagnostic_summary.json`。
