# 当前证据与下一步优先级（2026-09-28）

本次为实际代码、保存产物和服务器日志的分析，不提交训练。以最新同容量 full-history/repeat-last 对照为准；此前“下一步补八帧”的建议已过时。

## 当前证据

- 额外低COT惩罚移除后，最佳学习候选的厚云RMSE从28.279降至26.856，仍未胜过同实验step-0输运26.504；该损失项有方向性影响，但不能解释全部失败。
- 同容量15通道头、同初始化、相同256次更新的八帧历史/重复末帧试验已完成，服务器日志有`SILI_FULL_VS_REPEAT_LAST_COMPLETE`。按厚云patch RMSE选模，两臂都回到step 0。最佳学习候选的站点厚云RMSE为27.606/27.609，输运为25.163。full-minus-repeat的按初始化日bootstrap区间跨0。这不证明历史信息无效，只说明当前输入表示和训练合同没有获得稳定增益。
- 当前全历史实现把8张历史COT作为8个通道，复制到16个预报时效；没有显式沿云运动路径对齐历史。当前运动仍是局地历史C13估计的一个平移向量。不能称为已经学习到了可靠云团轨迹。
- 64×64完整patch在+240分钟的输运支持比例为78.6%，它不是站点上游缺失比例；须分别报告站点、邻域、patch支持度。
- 已有区域GHI pilot：预测COT和oracle-COT相对zero的两站等权RMSE差为−0.570和−4.383 W/m²，对应日期bootstrap区间均跨0；oracle是R(真实未来AGRI)，不是独立物理真值。更准COT有价值的假设仍需站点GHI端验证。

## 本次发现的评估问题

服务器`train_sili_history_repeat_control_20260928.py`的`aggregate_snapshot`使用`torch.expm1(f[:, 0]).expand(-1, 16, -1, -1)`作为SimVP预测；在`f=[B,16,1,64,64]`合同下，这是把第一时效复制16次。应保留时间轴，使用`f[:, :, 0]`。本次原样源码见`audits/next_step_review_20260928/history_control_source_as_observed.py`。

该错误位于SimVP基线评估字段；模型输入使用`forecast.permute(0,2,1,3,4)`，保留16时效。因此它不直接影响full/repeat的训练、选模以及与transport的比较，但这版SimVP基线行不能用于排名。先另存修正后的只读评估，检查固定baseline在同键、同mask下跨脚本一致，不重训、不覆盖原始结果。

## 推荐执行顺序

1. 修正上述SimVP评估行并做固定baseline一致性验收。shape一致不足以证明时间轴正确；必须以逐lead的真实数组比较，保留原始产物。
2. 复用固定验证cohort，按天气过程和日期去重检查实际云事件，分解三段：R(真实AGRI)对CPP的反演误差、固定输运的位置/到达时间误差、位置对齐后仍剩的厚度和增长消散误差。诊断性位置对齐需要未来参考，只能作为离线归因，不是可部署预测。不同替换之间有相互作用，不能把误差降幅直接当作可相加的因果贡献。
3. 在同一冻结R和同一运动估计下，只扩大历史来源域64→128→256，仍评价同一站点/局地目标。分别报告共同支持域精度、各来源域覆盖率以及原来无来源记录，不能靠排除困难像元制造提升。先做无训练的来源域对照，不立即重训大模型。
4. 由结果选择一个改动：反演已偏薄则先校验该时段反演/CPP来源及太阳几何；扩域有效则采用区域上游输入；位置对齐大幅改善则优先运动估计/路径对齐；对齐后仍漏厚云增长则设计单因素厚度演变目标。任何新学习方案都保留输运回退，保存best-learned与selected权重及逐样本结果。
5. 候选通过独立日期的站点/邻域、远时效和误报约束后，再进入同样本同架构GHI头的配对验证。COT≥30指标只作当前厚云失败诊断，不能代替最终15min GHI误差和突变时序指标。COT更接近CPP不保证GHI更准。

## 停止条件和范围

当前连续追加同一种厚度残差头、重复八帧消融或扩大其训练轮数，优先级低。先完成上述无训练归因；一个改动不能在固定验证合同下超过基线，就保留负结果并结束该候选，不继续搜索到正结果。独立test保持关闭；IFS增量等待COT主链与发布时间合同；本次不修改论文结论。
