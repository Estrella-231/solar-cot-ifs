# 四里/竺家天气分组COT异常诊断

2026-09-12对已保存validation预测做只读诊断；没有训练、选模或读取test。源为天气头逐行类别、head pack四维COT特征及original/QC1各seed42/43/44的A/AC预测，全部核对SHA、pack_row、真值、站点和时效。

## 主要结论

四里QC1预测晴天组的退化是广泛、稳定的系统偏差，不是少数极端COT、晨昏样本或天气分类错误造成。加入COT后，三个AC模型相对各自A模型平均把GHI预测再降低18.75、18.87、9.80 W/m²；A本身已有−47.69、−31.16、−41.15 W/m²的负bias，因而低估被进一步放大，RMSE分别增加13.92、14.17、6.29 W/m²。

这说明已观测到的直接机制是“当前AC头在四里低云量条件下学到了过强的负向COT修正”。为何优化会形成该站点特异响应仍未由本轮证明，不能把它解释成COT的物理作用。

## 四里预测晴天的COT特征

四个输入是`log1p(COT)`场的patch均值、空间标准差、p90和中心像元，不是物理COT的四个统计量。四里预测晴天均值依次为0.0402、0.0281、0.0721、0.0346；竺家为0.0489、0.0387、0.1017、0.0387。四里没有比竺家更大的尾部或明显异常，反而整体略低。四里空间标准差最低四分位退化最大（+16.50），中心COT最高四分位退化最大（+19.84），但其余分位也全部退化，不能归因于单一阈值。

QC1仅从训练集排除448条疑似平直段记录，其中四里192、竺家256，并在保留训练集上重新拟合近乎恒等的标准化。排除并不只发生于四里；本轮不能据此把问题归因于四里数据被大量删除。original与QC1还使用不同的固定学习率（0.0003与0.001），不能把两者差异单独归因于448行QC。

## 与竺家对照

竺家QC1预测晴天平均delta为−1.02 W/m²，三个seed为−1.68、+0.92、−2.31；各lead平均多数改善。参考晴天全集也保持站点反向：四里+7.33且3/3退化，竺家−2.28且2/3改善。因此合并站点的晴天+5.22主要是四里特异退化，不能写成湖南两站共同规律。

## 下一步实验建议

先做固定checkpoint的COT反事实前向：对同一批四里晴天样本分别输入原COT、训练均值COT（标准化零向量）、晴天中位COT和逐特征置换，保持AGRI、天气类别、模型权重不变。这能直接测出四个COT特征各自让同一个AC模型改变多少GHI，避免继续用两个独立训练模型的差值猜测机制。

若反事实确认是COT分支导致，应测试一个单因素表示：COT作为零初始化残差调制，并用因果天气概率软门控；A/AC保持相同初始化、学习率、参数量与样本。不要立即训练三个天气专家头，因为当前多云精确率只有36.91%，硬路由会混入大量阴天。
