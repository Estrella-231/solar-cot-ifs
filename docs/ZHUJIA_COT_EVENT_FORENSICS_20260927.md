# 竺家 COT 误差案例图（2026-09-27）

本图组取自已保存的竺家验证集，不使用测试集。每个序列包含未来 16 帧 SimVP 预测 AGRI、由该预测 AGRI 经冻结 R 得到的可部署 forecast-COT，以及将真实未来 AGRI 经同一 R 得到的 oracle-COT 诊断。右侧另绘同一序列逐时效的观测 15 分钟 GHI 标签、无 COT 头输出和直接 COT 融合头输出。

AGRI 小图是将模型归一化输入中的 C02、C03、C13 做逐序列对比度拉伸后组成的伪彩色代理图，帮助看云场变化；它不是经标定的卫星 RGB 产品。COT 已从 `log1p(COT)` 还原为无量纲光学厚度，并在 forecast/oracle 两组之间共用色标。

## 三个验证案例

- 序列 4106，+225 分钟：观测 GHI 825.19 W/m²，无 COT 头 441.72，直接融合头 257.84；直接融合的平方误差比无 COT 增加约 174,838 (W/m²)²。
- 序列 4115，+150 分钟：观测 287.38，无 COT 头 593.85，直接融合头 371.87；直接融合修正方向有利，平方误差减少约 86,782 (W/m²)²。
- 序列 1412，+165 分钟：观测 928.70，无 COT 头 489.57，直接融合头 431.62；两者均明显低估，COT 又把预测向更低值推，平方误差增加约 54,255 (W/m²)²。

这组例子显示直接 COT 融合的修正方向并不总错；问题是它在一些样本上压低了本已偏低的预测，而另一些样本里修正恰好减少过预测。它们是按验证误差挑出的案例，适合定位错误形态，不能代表总体频率或证明物理因果。forecast 与 oracle COT 图之间的差异能提示外推 AGRI→R 轨迹可能失真，但 oracle 由同一个冻结 R 产生，不等于 CPP 真值，也不等于独立物理观测。

此外，当前竺家残差 v2 的验证选模回退到 step 0，所以其最终逐样本预测与无 COT 基线完全相同；这组图展示的是之前直接融合头相对无 COT 头的验证行为，不是残差头学到的修正。
