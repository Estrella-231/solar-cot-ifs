# COT 因果时空轨迹方向（2026-09-18）

## 本次决策

先前的完整 COT 图候选把某一预报时效的一张 `16×16` COT 图送入 GHI
头，并在读出时保留站点、邻域和全 patch 特征。它能检验单时刻空间场，不能
检验云厚度的演变是否为站点辐照度提供额外信息。因此它不再是本论文的主候选，
只保留为静态空间对照。

新的主候选为 `causal_cot_trajectory_solarresnet_v5`。它不使用全图平均、COT 四统计量或
静态单帧读出；它编码站点邻域内 COT 的历史和未来预报轨迹，再只在站点像元
`[8,8]` 读取结果。

## 因果输入合同

对初始化时刻 `t0` 和第 `k` 个未来 15 min 时效（`k=0,...,15`）：

```text
历史 AGRI: t0-105,...,t0
    -> 冻结 R
    -> H = [COT(t0-105),...,COT(t0)]

8 帧历史 AGRI
    -> 冻结 SimVP S
    -> 预测 AGRI: t0+15,...,t0+240
    -> 冻结 R
    -> F = [COT_hat(t0+15),...,COT_hat(t0+(k+1)*15)]

[H,F] 的因果前缀 + 当前第 k 张预测 AGRI + 几何/站点/lead
    -> 因果 3-D COT 编码器
    -> 站点 [8,8] kt
    -> 目标 15 min 窗口 GHI
```

`F` 中所有 `k` 之后的图在进入网络前置零；不能因 SimVP 在 `t0` 一次生成了
16 帧而提前使用后续预报图。历史端只读初始化前的真实 AGRI，不读未来真实
AGRI、未来 CPP、GHI 或测试集。S 和 R 均冻结且禁止反向传播。

## 网络与“空间结构”的含义

`CausalCOTTrajectorySolarResNetV5` 的 GHI 主干为湖南每个站点从头训练的残差图像
编码器，包含 CBAM、中心像元分支与 5 维 metadata MLP；不加载或复用湖北
Direct-GHI 权重、归一化或样本。图像端采用当前目标时刻的 16 通道
`13 AGRI + cosSOZ + cosRAA + day_mask`；metadata 为确定性的
`[cosSZA, hour_sin, hour_cos, doy_sin, doy_cos]`。

COT 分支仍由四层时间左填充、空间对称填充的 `3×3×3` 空洞卷积组成，膨胀率依次
为 `1,2,4,8`。其输出在目标时间索引、站点位置 `[8,8]` 提取 32 维向量，再与
SolarResNet 图像/metadata 特征融合。该向量可由历史和可用预报前缀中站点周围的
厚云形状、移动方向、靠近/远离站点的变化构成。它没有全 patch 均值或 COT 显式
统计槽。

训练时仅用一个由**唯一训练序列**所有历史/预报 COT 像元和时间点计算的标量
mean/std 标准化输入。这是固定数值尺度，不作为模型读出特征；每个样本的空间
排列和时间顺序仍保留。

## 配对消融

四组使用同一 SolarResNet-style 头、初值 seed、样本行、16图像通道、5维metadata、
标签、可用性掩码、优化器、有效 batch 2048 和训练步骤：

| 组 | 历史 COT H | 预测 COT 前缀 F | 回答的问题 |
|---|---:|---:|---|
| `A_ST` | 零 | 零 | 同容量、同时间掩码的 AGRI 基线 |
| `AC_H` | 输入 | 零 | 初始化前云厚度轨迹是否有用 |
| `AC_F` | 零 | 输入至 k | 预测云厚度轨迹是否有用 |
| `AC_ST` | 输入 | 输入至 k | 两段连贯轨迹是否有附加收益 |

先在原始训练/验证 cohort 做 seed42、10 epoch 探索性 pilot。保存每组逐样本
validation 预测后才允许审计；未经稳定多 seed、空间排列对照、来源门禁和一次
冻结测试，任何差异都不能写成 COT 物理因果、普遍提升或论文最终结果。

若 `AC_ST` 出现可重复改善，后续空间排列消融会以每个时间帧同一个固定坐标置换
破坏空间位置关系、同时保留该帧 COT 值分布；它检验的是空间对应关系，不能再用
全图均值替代。
