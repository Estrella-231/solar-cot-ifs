# 湖南 SimVP 结构审查与候选改进

日期：2026-10-08。范围：当前月度新划分 SimVP 的保存代码、训练元数据与既有验证诊断；不是服务器实时状态查询，不启动训练、不替换第二篇冻结骨干。

## 1. 已核对的实现

权威代码为 `experiments/monthly_block_20261002/source_snapshot/triad_models.py` 中的 `SimVPBackbone`，以及同目录 `simvp.py`。本次计算的两个源文件 SHA256 与 `audits/handoff_20261003/simvp_run_metadata.json` 一致：

- triad_models.py：9273447d357bad92bcf3cd976b65fb4c440187da456fb56d5f36ded349c681eb。
- simvp.py：2e0d280f7962a77f0c9b7e4cc817fed21d142c1436a12eb858e3234485313d16。

输入为8帧13通道历史AGRI，以及按时间排序的24帧3通道太阳几何。每次SimVP调用接收8帧16通道，输出8帧13通道。空间处理范围256×256；站点GHI输入patch的16×16不是该外推骨干的空间范围。

```text
8×16×256×256
 → 逐帧四层编码器（两次stride-2）
 → 8×32×64×64
 → 时间并入通道：256×64×64
 → 八层gSTA，hidden=256，MLP ratio=8，kernel参数21
 → 8×32×64×64
 → 解码器，两次PixelShuffle，上采样至256×256
 → 8×13×256×256
```

第一轮覆盖+15～+120min。第一轮预测与这8个目标时刻的几何拼接后作为第二轮输入，第二轮覆盖+135～+240min；两轮共享权重，第一轮输出未detach。每轮输出还加上对应目标几何的3→13通道1×1投影。该投影初始化为零，但训练后的权重不能据此认定仍为零。

编码器保留一个全分辨率浅层skip，解码器末层前相加；没有完整的多尺度skip，也没有显式的运动对齐skip。时间并入通道仍能学习有顺序的时序映射，不能说模型“完全没有学习时间”。

从静态代码看，未发现上述主链存在帧数/通道数不匹配、未来AGRI输入或第一轮detach错误；这不等于完成运行时与所有数据来源审计。当前默认Python没有torch，未执行张量前向、反向或吞吐测试。

## 2. 已有证据与可检验假设

保存的训练元数据：随机初始化、新train/val、12轮、batch8、训练35320窗口、验证3140窗口；损失为归一化AGRI有效像元MSE，选模为四季等权验证RMSE，test载荷读取0。以上为完成资产的记录，不是实时队列状态。

`docs/COMMON_VAL_OLD_NEW_SIMVP_20261003.md` 的同架构新旧模型诊断只覆盖4个夏季日期、22个窗口：新模型通道像元误差改善，但仍有厚云压薄和到达偏迟。7月9日四里案例，真实未来AGRI经R反演的5×5诊断邻域峰值67.36，新预测AGRI经R为7.28；这是邻域代理诊断，不是站点单像元CPP真值。8月22日四里10:00，CPP站点COT首次达到10在+180min，新预测在+225min；真实未来AGRI反演在+165min，说明参考之间也有差异。

这些证据支持同时检查厚度幅值与到达时间，不足以证明某个新增模块一定有效。MSE在不确定的云位置/演变下可能鼓励平滑；但数据、反演误差、训练与位置偏差均可能贡献，不能只归因网络容量。

## 3. 优先级与独立对照

|顺序|单因素候选|要解决的具体问题|实施边界|
|---|---|---|---|
|A|保持gSTA骨干，改为历史8帧直接输出未来16帧|后8帧必须依赖前8帧预测，可能累积漂移和压薄|显式修改translator输出至16×32、decoder批维与skip时间映射；不能只改reshape。保留原太阳几何投影和输入合同。记录参数/FLOPs/显存变化，必要时补容量匹配对照|
|B|在A或原基线内独立加入未来几何的特征调制及lead embedding|当前目标几何主要在输出端作线性加法，难以与云状态非线性交互|几何逐时效、逐空间位置进入latent/decoder；按identity调制初始化。B与A先分别比较，不能一次改完后归因|
|C|运动对齐的多尺度skip/局地特征输运，加受约束的演变残差|恢复云边缘、到达时间及增厚/消散|运动只从历史估计；避免直接复制未对齐历史云；边界出域必须有支持掩膜，不能循环回卷；反射率受太阳几何影响，不能强行当守恒量|

暂不优先叠SE/CBAM或全面换Transformer：现有gSTA已有门控与大核空间注意力；新增模块必须针对明确缺陷。局地时间注意力或3D卷积是候选，但应在直接16帧对照后，明确其增量问题与预算再立项。

当前 `refine-logs/simvp_supervision_20261003/EXPERIMENT_PLAN.md` 已安排同架构MSE/时间变化/空间梯度监督对照，应先收集其完成输出和独立重算结论，避免把已有损失路线重复当作新结构创新。其本地tracker是10月3日快照，本次未刷新服务器，不能据此声称仍在训练或已完成。

## 4. 评价与推进门槛

新结构独立命名，按新月度train从随机初始化训练，不覆盖冻结基线、不读test载荷，不改变第二篇已启动合同。保持归一化、数据次序、训练预算和标签一致；比较须说明参数量、训练算量以及吞吐，不能只按相同epoch判断公平。

第一阶段只做train小批前后向与单卡profile，保留稳定余量；通过后才开展验证实验。qsub前查询账户全部未结束任务，遵守最多3任务、8GPU。当前审查没有提交PBS任务。

在相同验证支持上保存完整16帧预测，分别比较+15～120与+135～240min：物理AGRI通道误差、云边缘/空间位置、站点厚云峰/持续时间/到达偏差与晴空虚警；跨日期配对统计而非仅展示最差个例。COT评价先核验新划分R来源与有效CPP支持。最后用相同GHI头重训做下游闭环，AGRI更好不自动等于GHI更好。

采用候选的条件：目标时效/事件问题有跨日期一致改善，且晴空虚警和其他时效无不可接受退化；否则保留基线并记录负结果。数值阈值需在读取候选结果前冻结，不能事后调整。

参考：[SimVPv2原论文](https://arxiv.org/abs/2211.12509)。该论文支持gSTA机制背景，不是上述候选在湖南有效的证据。
