# 新月度 R 的云/厚云识别验证

日期：2026-10-13（BJT）  
对象：`monthly_R_station16_COTUNet_seed42_v1`，独立验证集  
参考：质量掩膜内 CPP COT。CPP 是检索参考，不视为独立真值。  
使用数据：1,398 个验证站点样本，356,169 个有效像元；没有读取 test 载荷。

## 定义和计算

模型保存的是 `log1p(COT)`，评价时对预测值执行一次 `expm1`，回到物理 COT。按预先固定的阈值做二分类，不在验证集上搜阈值：COT ≥ 0.1 作为“有云 COT”代理标签；COT ≥ 30 作为厚云标签。只在 CPP 有效掩膜内统计，缺失或无效像元不当成晴空。云识别结果因此是 COT 阈值识别能力，不能替代独立的 CPP 云相/云掩膜分类评价。

报告 POD=TP/(TP+FN)、precision=TP/(TP+FP)、FAR=FP/(TP+FP)、CSI=TP/(TP+FP+FN)、频率偏差=(TP+FP)/(TP+FN)。

## 解读边界

模型对 COT≥0.1 的像元有较高检出率，但预测云像元总数约为参考的 1.10 倍，说明有一定云虚警。厚云识别明显更难：合并 CSI 约 0.50，仍有约三分之一参考厚云漏报，且约三分之一厚云预测为虚警。两站差异也值得保留：四里厚云 POD/CSI 较低、虚警比例较高；竺家相对好一些。此结论针对 CPP 支持的白天验证像元和该 seed，不代表跨季节/多 seed 稳定性，也不说明 COT 对 GHI 的因果增益。
