## 对下一步的含义与限制

这支持“混合CPP与R回退目标可能改变监督组成”的机制假设，因此保留已准备的CPP-only单因素对照：相同样本、初始化、seed、更新预算和AGRI损失，只移除CPP无效处的R回退监督，并重新按训练数据校准辅助损失权重。当前M1尚未完成，按预注册门槛不提前启动CPP-only，也不根据本验证诊断调整权重。

CPP是卫星反演参考，R又是由AGRI派生的反演器；共同支持差异不是独立真值误差，更不能单独证明R回退导致GHI退化。本审计没有评估模型技能或未来GHI收益，结论仍须由M1/C​​PP-only的同掩膜复算及后续配对GHI验证决定。
