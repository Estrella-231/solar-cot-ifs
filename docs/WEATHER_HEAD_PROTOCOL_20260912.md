# 晴天/多云/阴天天气分类头

用户2026-09-12明确要求训练天气分类头并按预测类别重新比较COT，随后明确类别为晴天、多云、阴天。本轮不训练水云/冰云分类器。

标签采用修正CPP sidecar的16×16区域CLP：0无云，1+2均为有云。至少231/256像元有效时，云覆盖比例≤20%为晴天、>20%且<80%为多云、≥80%为阴天。其含义是目标瞬时站点周围区域云量代理，不是气象台地面天气或全天气象分类。源缺测/无效覆盖单独保留，不当晴天。阈值在训练前固定，不按结果调整。

原冻结train/validation全部43122个独立(station,target_time)读取，不依云类别或辐射误差选样；原256验证子集不作为训练集。所有源读取保留路径、UTC/站点核对、SHA及缺测状态。CPP生产绑定尚未闭合，因此CLP只称参考伪标签。

分类器输入为冻结湖南SimVP外推的13×16×16 AGRI、3维太阳几何、站点和时效。未来真实CLP仅作监督；未来真实AGRI、实测GHI/kt和COT均不输入分类器。A/AC使用同一分类器输出，避免分组样本不公平。S/R及已有GHI预测头均不重训。

模型两层CNN(13→16→32)、全局池化、站点/时效embedding、47→64→3 MLP，seed42，AdamW lr0.001/wd0.0001。交叉熵按训练独立目标的类别频率和每目标重复预测行数加权。最多30epoch、patience6；仅用原train内最后20%的UTC目标日期选模，边界前一日排除，防同初始化跨内部fit/tune。原验证集不参与梯度/选模，test不开启。

先单卡profile 128/256/512/1024/2048，取最高吞吐95%以内的最小batch，至少20%显存余量；不为填显存开多卡。24条三类平衡训练行过拟合只作数值检查。输出分类混淆矩阵、accuracy、macro-F1、各类precision/recall、分站/时效、目标等权结果与训练多数类基线。保存所有验证行的分类概率，CLP缺测不排除预测分组。

重新使用已有original/QC1、GHI种子42/43/44的12候选保存预测，在共同预测天气组内重算GHI RMSE/MAE/bias及两站等权AC−A，报告全部种子、均值、样本std。另列参考天气组仅作诊断，不做oracle路由。分类头只有一个种子，GHI三种子不能替代分类器稳定性验证。本次不训练分天气GHI专家头，不声称精度必然提高。
