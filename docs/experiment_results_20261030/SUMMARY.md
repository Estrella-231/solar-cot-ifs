# COT反演、同期GHI估计及未来预报结果汇总

整理及更正日期：2026-10-30。首版漏列10月29日完整湖南冻结验证，导致“预测COT尚无稳定收益”的总判断过于笼统；本版已补入并重写结论。依据保存评分及来源审计，并从最新63,480条预测独立重算点指标和5,000次日期块区间。未提交训练、未重新推理全套模型、未打开test/buffer数值载荷。`metrics.csv`含125项指标，`SOURCE_INDEX.json`绑定21份来源及其SHA，`LATEST_HUNAN_RECHECK.json`记录本次重算。数值清单可由`build_summary.py`生成。

## 一、目前最重要的结论

1. **真实目标云图反演COT，再加入同期GHI估计，已有正收益。** 湖南单帧清洗后为108.181→103.995 W/m²，点降幅3.870%，日期块区间不跨零；但这是旧验证选模权重的固定重评分，且反演隐藏特征对照同样有效，不能宣称已分离出COT物理语义的独有贡献。
2. **预测COT在最新湖南SimVP冻结头验证中已有小幅正收益。** 127.421→125.340 W/m²，降幅1.633%，目标日期块差值95%区间[−3.714,−0.561]不跨零；原冻结两日块敏感性区间[−3.870,−0.406]也不跨零。两站六个种子配对点估计均改善，但竺家单站区间跨零，不能说每站均显著。同期真实三帧训练的配对头冻结后接预测图，属于重复使用验证集的回放，不是独立test或预报适配重训。湖北整链、未来残差及湖南直接预测COT的旧负结果不因此失效；它们是不同实验。
3. **历史COT的开发验证信号未在新夏季时段稳定复现。** 新来源三站主结果160.787→161.926；原起报时段子集仍未确认增益。缺效回退修复减少损害，但相对无COT仅改善0.052%，区间跨零。
4. **湖北完整修正后的同期主结果仍是缺口。** 4.49%属于错误CPP时标旧R；10.54%属于正确UTC但太阳几何整链修复前的同期候选。不能用后续预报结果填补同期主表。

### 为什么与此前负结果不同

最新实验采用“湖南SimVP→修正R→同期真实三帧训练的冻结配对头”；此前湖南直接预测COT实验采用U-only R/P、H训练的单帧预报头，且参考行范围也不同；湖北实验则区域、日期和头部均不同。不是同一实验的分数互相推翻，也不能据差值认定三帧、几何修复或某一单项改动导致了增益。首版汇总的错误在于漏掉新结果后，用旧实验否定了所有预测COT收益。

## 六、现有证据能解释什么

较早的真实未来图像反演COT条件信息探针：原冻结历史COT基底118.799；上下文修正124.850；加预测COT124.307；加真实未来图像反演COT99.569 W/m²。50个开发目标日期、32,838条共同记录、固定三折日期OOF。在该探针中，实际图COT含有可提取的GHI相关信息，但预测来源未保留同样收益；预测COT探针仍差于该实验已有基底。这不能否定最新湖南冻结头的1.633%增益。此项为离线诊断，99.569不是可部署预报成绩，也不能与其他队列分数直接相减。

来源替换和新夏季案例共同提示：底图漏掉增厚/空间细节是限制之一；历史可用域、缺效回退、预测COT分布误差与GHI映射响应也有影响。现有证据不足以把所有问题归为SimVP或单一反演误差。
