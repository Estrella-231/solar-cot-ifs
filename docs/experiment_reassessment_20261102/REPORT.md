## 2. 哪些旧结论必须缩小范围

| 旧结论或可能的理解 | 本次判断 | 对既有结果怎么处理 |
|---|---|---|
| “预测COT没有GHI收益” | 已不能概括项目。当前真实图训练冻结头的两个区域总体均有正收益 | 旧分数保留，原负结论只对应当时R、上游、头、样本和预算 |
| “竺家加入COT必然退化，只适合无COT” | 历史特定融合方式的结论；当前竺家点改善0.765%，但区间跨零 | 不删除早期退化案例；也不宣称当前竺家收益已显著 |
| “历史真实AGRI/反演COT直接预测未来COT没有价值” | 旧直接COT路线绑定U/H、U-only教师和预测域训练头，负结果不能推广到当前头；也不能只因取消隔离就预设会变好 | 先交叉回放现有P输出；不立即重训P。P相对CPP的厚云漏报、变化压缩仍是有效的对应模型诊断 |
| “真实图训练头一定比预测图训练头好” | 未证明。共同63,480条上旧头COT增量1.737%、新预测域头0.616%，但新头加COT绝对RMSE113.850优于旧122.788，且跨轮设置有混杂 | 当前按用户选择用真实图训练头；不拿增量较大当绝对精度最优或训练域因果证明 |
| “扩大数据量导致COT收益缩小” | 不成立。跨轮同时改变训练域、更新数、归一化、结构与重复目标时刻权重 | 真实独立目标时刻仅约增加1.9%；不把预测实例行数增加解释为天气样本同比增加 |
| “RMSE变好代表厚云和GHI都会变好” | 不成立。直接P的总体COT误差与厚云/15分钟变化表现不一致；CPP清零也曾损害GHI | 各指标按问题使用；有真实GHI即可测下游，不因某COT门未过就阻断 |
| “历史轨迹无用、完整空间场无用” | 旧历史通道堆叠/特定头、预算与预测源的阴性结果；未覆盖所有时空表示 | 保留原256更新等设置和阴性判定；当前不恢复用户排除的16×16 GHI头，不重启无界表示搜索 |
| “COT的物理语义独自解释当前7.763%和4.897%收益” | 当前有无COT头已同参数量，单纯增加GHI参数不足以解释；但冻结R还带来云产品监督、额外上下文和非线性表示 | 当前只能支持COT辅助表示有用；旧几何/单帧的隐藏特征对照不能直接补齐当前三帧机制证据 |
| “外推必然削弱COT相对收益；更好COT必然改善GHI” | 不能从湖北同期7.763%与预报4.897%直接推出，两者样本不同；湖南同一旧样本上真实图COT点增量1.29%反而小于预报1.74% | 需要同头、同键、固定另一路输入的替换分析。输入替换是条件响应，不是独立物理误差贡献的完整证明 |
| “3.87%单帧比1.37%三帧好，所以单帧最优” | R、几何、样本等不同，尚无纯帧数因果结论 | 保留单帧同期候选与当前三帧预报路线；不暗中更换当前头 |

上表区分了三类影响：旧规则导致没做必要比较、旧配置结果被过度概括、真实数据来源错误。规则改了不会自动让旧阴性实验变成阳性。

## 3. 来源错误必须另列

湖北旧CPP监督8小时时间错配的R及其4.49%不能继续作为有效主结果；包含已确认四里无效日的旧3.02%须使用明确来源的清洗后重评分。湖北10.54%已修正CPP时间、但仍用原太阳几何，属于被替代配置；不能与正确几何三帧7.763%拼成纯几何消融。以上不是取消OOF或改头后就能自动修复的分数。

## 4. 最值得补做：先做不训练的同头COT来源替换

**问题：旧直接预测COT的阴性结果，是未来COT本身的问题，还是依赖当时的GHI训练设置？当前预报还有多少对更准确COT输入的响应空间？**

优先湖南，因为已有保存的直接P-C/P-XC历史预测及当前真实图训练头。固定同一批预测AGRI、太阳几何、当前GHI头及其train归一化，在共同station/init/target上比较：

| 分组 | GHI头/输入 | 回答的问题 |
|---|---|---|
| 参照 | 当前无COT头＋同一预测AGRI | 保持可部署无COT基线 |
| 当前路线 | 当前有COT头＋R(预测AGRI) | 已有正结果的参照，已有输出不重算 |
| 直接P替换 | 同一个有COT头＋保存的直接未来COT | 换到当前真实图训练头后，直接COT是否仍更差 |
| 未来观测替换 | 同一个有COT头＋当前R(真实未来AGRI) | 离线诊断：保持AGRI预测不变时，对更准确COT表示的响应 |

未来观测只在单独的诊断组使用，不能作为预报成绩。直接P相对当前R还可能有教师、训练支持、标定及头适配差异；替换是判别实验，不等于完成了直接P的公平全train方法排名。不能靠这次结果拟合COT缩放系数或筛天气，不能借机改帧数/重训预测图头。

先盘点输出与键，不把不同时效串在一起；单帧P输出须按当前T−30/T−15/T真实时间重建有序输入，近端已知历史用初始化时真实历史，缺少的P输出可补因果推理。可部署各组用共同有效输入与原GHI掩膜；oracle先在同一全范围能取到的情况下比较，否则单列其可用共同子集且重算该子集所有参照，不用未来参考缺口改主表。

既有湖南63,480条上已做预测COT/未来观测COT/末帧持平替换，原结果分别122.788、108.941、129.516 W/m²；此部分复用，不重复整套前向。新增重点是直接P来源替换，以及湖北当前真实三帧头缺少的同键诊断。若湖北所需真实图尚未存齐，先做现有共同支持，不因此阻断湖南复查。

报告总体、站点、+15～30和+45～240分钟，以及按误差无关规则选取的改善/退化事件；使用原自然分布评价，按日期块报告不确定性。17个湖北日期不能被24,451条重叠记录包装成大量独立天气事件。事件图展示真实AGRI、不同来源COT和同一15分钟GHI，不用合成图代替实际输出。

**结果解释：** 如果直接P在同头下仍明显更差，优先检查其厚度/到达时间及教师差异，不再凭换融合方式续训；如果差距明显缩小或反转，则有依据设计一次当前教师、全train条件下的直接P候选。若oracle也无改善，说明该头在该条件下对更准确COT缺乏响应，应查表示及头适配；这不等于COT物理无效。上述结果决定优先级，不要求每站每时效CI都通过才允许开发。

## 5. 最值得新增的训练：正确几何下的表示对照

为论文机制归因，优先湖北当前真实三帧、小邻域、正确R与20,035条既定train。已有无COT/COT两个头直接复用；先核查是否存在同合同产物，再补必要的额外图像特征和冻结R隐特征对照。所有新增头仍使用真实图训练，冻结后接同一预报输入评价；不改变当前选用头。

保持相同局地空间支持、可训练参数预算、样本/标签、初始化配对、实际更新数和选模原则；记录R隐特征看过的16×16上下文，不能把它与仅看3×3的AGRI头当成纯物理语义控制。单独的R隐特征对照可以检验显式COT是否必要，不能自动分离额外上下文、云监督和全部非线性表示效应。需要精细分离时再设计相同上下文对照，不为此默认扩展一大套实验。

这一项比继续扩大外推网络更直接补强论文：若隐特征与COT相当，应将结论表述为“云产品监督表示有用，COT是一种紧凑可解释表示”，不能坚持COT标量语义独有。若COT优于合理匹配表示，才能进一步讨论其优势及适用范围。两种结果都可以推进论文。

## 6. 其余工作的次序

1. 同头替换和正确几何表示对照优先，不再默认启动五折OOF或预测图头重训。
2. 若论文需要论证单帧/三帧差异，再做同R、共同完整三帧候选样本、相同训练预算的帧数对照；否则作为候选与适用范围保留，不强制现在补。
3. 若要比较DyDiff与SimVP优劣，使用同区域同头同键，且已有湖南完整对照复用；不能因当前允许DyDiff便宣称其已显著优于SimVP。
4. COT清零/判云、区间平均与历史残差等旧阴性方案，只在同头诊断给出具体机制依据时选择一项复查，不全部重跑。
5. 独立确认、短临IFS增量仍各自有价值；它们不构成当前补机制分析和开发的前置条件，test依用户指令继续关闭。
