# 高辐照度低估与COT错误下调：持续问题记录

更新：2026-10-16。状态：**未解决；已有部分有效修正，不能重新登记为新发现。**

本记录连接历史结论与当前处理。当前诊断保持GHI的3×3、T−30/T−15/T三帧和冻结模型不变；不恢复16×16 GHI、全局均值或p90。反演器原有16×16上下文与GHI输入是两件事。仅使用train/validation，test关闭。

## 已经知道什么

1. A在一些高GHI情景本已低估，AC仍进一步降低，至少从2026-09-12起就已记录。不同实验合同下再次出现，属于问题复现，不能称新的机制发现。
2. “允许双向输出”只解决表达能力，不保证模型学会何时向上修正。已做过零初始化残差、OOF、统一特征编码；不能再次把这些未加区分地建议为新方案。
3. COT反演更准、硬清零更少、加入历史或修正太阳几何，都不等于高GHI映射问题已修复。总体RMSE、该错误子群、COT额外价值必须分别验收。
4. R-COT与CPP接近时仍有严重GHI低估；当前也有COT近零却AC进一步下调的样本。不能把两套独立训练头的AC−A全部解释为COT直接衰减，更不能把所有错误归于反演器。

## 执行断点与后续约束

本次工作的具体遗漏是：此前把最新实验目录作为下一步依据，没有先接续上述诊断—修正—结果链；把总体改善、R修复和目标失败子群混在一起；没有持续连接同一失败病例；再次提出已经执行过的诊断，甚至错误建议恢复已取消的16×16 GHI。责任在实验承接与解释，不以“上下文太长”替代说明。

后续实验说明必须引用本记录，并写清**相对哪次已完成修正，唯一新增的因素是什么**。当前不追加训练、不重新审计已通过的BJT/UTC、标签均值、像元索引，也不把这次连接当成新物理结论。

下一项修复的目标应是GHI条件映射中尚未解决的向上恢复和COT额外价值；仍需区分可由输入辨识的情景与输入不足。训练分布失衡、均方损失的条件平均、云边辐射增强、实际云影错位均只是候选原因，当前证据没有选出唯一根因。不能据此直接加权高真值、推理时用实测选方向，或重复一个同结构残差实验。

在保持用户当前3×3、三帧及模型不变的诊断范围内，已完成动作就是上述旧修正—当前失败的逐样本连接。若下一轮改变损失、映射或投影，须另列唯一因素与当前合同的公平基线，不能把旧单帧残差的111.277直接对比本轮三帧的108.236来宣称优劣。
