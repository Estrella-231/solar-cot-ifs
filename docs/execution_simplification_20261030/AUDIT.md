## 没有删除的检查

1. 正确UTC/BJT、太阳几何、真实像元索引、15分钟平均标签、相同评价行：这是曾造成真实错误的必要检查。
2. 原封存test/buffer关闭、真实未来观测不进入推理、无COT对照不伪造：继续执行用户规则。
3. 全部站点与负结果保留，macro指标、分站和日期不确定性如实报告；不能用1.633%宣称每站均显著。
4. 队列≤3和不操作他人作业：用户明确的资源约束，不是额外保守。
5. 旧模型确实存在时标、几何或输入归一化错误时，不能为了省事直接当成修复版；应只重建受影响部分。
