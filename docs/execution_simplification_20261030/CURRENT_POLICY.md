# 第二篇实验的简化执行方式

2026-10-30，承接用户对额外U/H隔离及过度防御的纠正。本文件修正执行默认值，不改写已经完成的实验设置、结果或原判据，也不恢复已暂停的作业/定时。适用第二篇`solar-cot-ifs`的后续普通开发；第一篇已批准训练不受影响。

## 默认怎么做

1. **上游默认使用全部train。** 复用来源与输入定义已核实的现有SimVP、R、归一化和预测产物。上游在train上产生输出、再用于训练下游，是允许的级联训练方式；不能仅因上游见过这些train样本就称数据泄漏，或强制重训U-only/五折模型。只有研究明确针对cross-fitting、stacking偏差等问题时，另设可选对照。
2. **不再默认层层拆训练集。** 不自动增加U/H、F/C、F_fit/F_select/C_fit/C_select及额外内部buffer。原train/validation/test及已冻结外层时间buffer仍按用户批准的清单执行。某方法确需校准留出时，只增设必要的一层并说明用途与数据成本，不推广成所有方法的要求。
3. **GHI头允许两条有效路径。** 真实同期输入训练后冻结用于预报，和使用预测输入训练头，均可按实际未来输入评价GHI。冻结头结果不因“没专门在预报图重训”而一律降为不可用诊断；预报重训也不默认优于冻结头。具体比较使用相同评价行，报告训练域和输入帧数。
4. **直接测最终目标。** 有完整有效预测和地面标签时，可以先做廉价、成对GHI评价。CPP覆盖少、COT RMSE未改善、厚云某项指标区间跨零、文献口径未齐，都不单独阻止GHI实验；相应问题限制COT结论并单列报告。不能用COT指标替代GHI收益，也不能因COT指标未过门而假定GHI必无收益。
5. **开发验证可以继续使用。** validation允许选checkpoint、比较候选、分析误差；无需每试一个想法都索取新的观测期或再加OOF。保留已尝试方案与负结果，区分开发验证和独立确认；新数据/封存test用于确认泛化，不是普通开发的通行证。不得改样本或换统计口径追求正结果。
6. **主指标与补充指标分工。** 按当前科学问题事先确定一个主要比较和总体指标，站点、时效、云况及种子变化完整报告。不能临时要求“每站每时效每项CI均改善”才允许开发、画图或写论文；严重退化需如实解释。总体有利也不能写成每站显著。已完成实验的原多重门槛结论保留，不事后改成通过。
7. **一次足够的检查可复用。** 新/改变的输入接口做小样本时间、空间、标签、单位、归一化与重载核对，正式结果从保存预测复算。数据/代码/权重未变时引用既有结论，不重复全量恢复、全文件重哈希、多轮独立复核或审查收据等待。已知错误或新差异出现时再针对复核。哈希和元数据用于追溯，不能替代数值检查，也不应变成每一步的审批流程。
8. **按问题选预算。** 新想法可先做小规模工程验证，再在数据有效时做成对主实验；正式比较按统一预算完成。多种子与敏感性用于结果确认，不能要求每次接口调试或小改动先做完整多种子/全套附加对照。预定正式预算启动后不因看到某臂正负而选择性提前结束。
9. **按资源提速。** 长任务沿用用户2026-10-21多卡规则；没有8张GPU总并行上限。评价优先3—4卡，跨工作区未结束PBS任务≤3；不占用或终止他人任务，保留已有断点。不把历史单卡profile外推成所有任务只能单卡。

## 必须保留的底线

- 时间系统、经纬度/真实像元索引、15分钟右闭标签窗口、物理单位和有效掩膜正确。
- 模型参数和归一化只用train拟合，validation可用于开发/选模；test/buffer数值载荷仍依现有用户指令关闭，不以本次简化为由打开。
- 真实未来AGRI/CPP可以作为train目标或教师监督；不能进入可部署的未来推理输入。太阳几何等初始化时可计算量可以使用。
- 方法间使用相同站点、时刻、真值与评价掩膜；不因成绩筛样或删除退化站点。
- 保留 checkpoint、关键配置及保存预测；反演、预报、离线未来参考分别报告；CPP是检索参考而非独立地面真值。
- 用户指定的站点3×3、小邻域/不使用全图均值p90、单帧同期主候选与三帧补充等范围决定继续保留；本次不借简化改变网络、数据划分或论文研究范围。
