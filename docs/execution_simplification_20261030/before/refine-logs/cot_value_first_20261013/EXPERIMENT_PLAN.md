## 1 主张与完成定义

**C1，主主张**：在真实AGRI条件下，加入反演COT能否改善湖南站点15分钟均值GHI估计？

**C2，应用主张**：固定合规外推方案后，COT能否提供GHI预报总体增量？COT自身外推误差是必须独立交付的证据，不另立外推创新主张。

排除解释：额外参数、R间接读取更大视场、同源CPP监督、样本筛选或优化预算不同造成的表观增益。COT来自AGRI，不声称新增独立观测。C1不成立时不能用不断更换外推模型挽救结论；C1成立而C2较弱时先做有限误差归因。

正文只保留五块：数据验收、同期反演主结果、COT作用诊断、COT外推精度、GHI预报应用。IFS、外推骨干研发、大范围尺寸扫描和diffusion均非本轮必做。不能把已有历史负结果删除，也不预写提升。

## 4 B1：真实图像下的反演主实验（最高优先）

| 组 | 输入 | 回答的问题 |
|---|---|---|
| R-A | 真实AGRI局地场+相同太阳几何 | 无COT基线 |
| R-AC | R-A + 同时刻R(真实AGRI)的局地COT场 | 加入COT的增量 |
| R-AP | R-A + AGRI学习特征分支，输出尺寸与COT分支一致 | 增量能否由额外有效容量解释 |

两个站分别训练，3组×3seed×2站=18次小头训练。先运行seed42的6臂，验收后运行另外12臂；不根据seed42正负取消其它seed。参数尽量匹配，报告全部可训练参数/FLOPs；AP允许调宽使总参数与AC相差≤5%，与A/AC共享训练预算。AP控制有效容量，但不控制R的大视场和CPP监督，这两点由B2补证并限制表述。

主要终点：各站所有有效样本GHI RMSE的等权平均。次指标：MAE、bias、每站、四季、月份、太阳高度与云况分层。相同样本比较R-AC−R-A及R-AC−R-AP，不按天气子集取代总体成绩。

成功判据：报告三seed平均差值、每seed方向和日期块95%CI。至少2/3种子同向且日期CI整体<0，才称该验证合同下有稳定收益；独立泛化主张仍待test。CI跨0称未确定，不用小数点上的正改善充当定论。工程验收通过且三seed无稳定增益，则最多做B2定位，不自动追加网络/seed搜索。

## 5 B2：COT物理作用与适用天气（无需大量重训）

必做：

- 从R-AC保存预测作配对残差分解，检查晴空误报云、薄云、厚云与云变化日。优先用合格CLP云覆盖/云相和CPP-COT事后标签；分类阈值在看新val结果前冻结。沿用晴≤20%、阴≥80%、中间多云；低COT<0.1、厚COT≥30，其余另列并给样本数。不把天气分类器的预测类别视为无误差真值。

- 每站四季各2个事件，合计16个案例：每季1个按参考云场变化规则选取、1个固定时间哈希选取；看GHI误差前冻结列表。画真实AGRI合成色图（标注伪彩配方）、物理COT、太阳几何、15分钟GHI真值/A/AC。再补最好/最坏病例时另列为事后案例。

有条件增加R-AL：同一R的局地隐特征替代显式COT，6次训练（2站×3seed）。在R-AC出现收益或R视场/监督归因无法解释时启动，预先固定选层和压缩维度，不搜索最优层。共享R感受野与监督，缓解但不能完全消除表示容量差异。没有该证据不宣称收益独属于COT物理语义。

T17冻结阶段结论：R1可靠增益则进入应用验证；无增益但有明确实现错误，另名修复全部受影响臂；无增益且无错误，则收缩为适用边界结果，外推评价可以完成，但不自动训练一大批预报头。

厚云指标含COT≥30的漏报/虚警、峰值幅度与到达时间。样本少时只描述不作显著性结论；多峰事件不将逐帧argmax跳跃当作同一云团轨迹。

## 7 B4：固定外推下的GHI增益与有界归因

前提：B1/B2阶段决策支持继续，S/R及train预测bank合规。预测bank必须含train和val；禁止用真实未来AGRI代替训练时的预测AGRI，否则产生输入域不匹配。

| 组 | 共同输入 | COT分支 |
|---|---|---|
| F-A | 相同预测AGRI、历史AGRI与几何 | 无 |
| F-H | 同上 | 8帧真实历史AGRI反演COT |
| F-F | 同上 | 初始化时可生成的预测COT截至目标lead前缀 |
| F-HF | 同上 | 历史+预测前缀 |

两站×4组×3seed=24次。所有组共享历史AGRI条件，避免把F-H收益误当新增历史观测的收益。COT支路保持显式时间轴，用既有通过witness的因果时间卷积候选；配置在训练前冻结，未来lead后COT不参与当前读出。所有组共同架构/预算，置零组仅作因子对照，不声称已经控制有效容量。F1不同时比较2D与3D。

首轮8臂seed42只检查工程/总体走势，其余16臂按预先阶段决策执行。主要比较预先固定F-HF−F-A，另报F-H−F-A、F-F−F-A、F-HF−F-H，不从四组里挑最有利一组替换主要比较。

若C1稳定而C2弱：最多增加F-O 6次（两站×3seed），固定预测AGRI条件、把未来COT换成真实目标AGRI反演COT并公平重训；另作冻结头替换诊断。F-O是离线诊断，无部署资格，不称严格上限。只能在更准COT带来GHI变化的配对证据下讨论误差传播；否则继续承认H映射与优化的限制，不无限改外推。
