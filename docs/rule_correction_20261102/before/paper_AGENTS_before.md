# 论文写作规则

修改本目录的论文、中文对照、论文计划或图表说明前，必须阅读 [WRITING_REQUIREMENTS.md](WRITING_REQUIREMENTS.md)。该文件规定科学问题导向的叙事、实验命名、语言和正文信息取舍。

论文结构以 [PAPER_PLAN.md](PAPER_PLAN.md) 为准；planning_history 只保存历史，不覆盖当前方案。实际实验状态从工程计划和保存产物核实，不从论文占位文字推定。

修改英文 LaTeX 正文时，必须同步中文 Markdown 的章节、公式、数值和结论，保存后用内置编译器核验。仅修改写作规范、计划或文献笔记无需改动正文。服务器路径、哈希、任务编号、修复过程进入工程文档；必要的时间定义、数据划分、输入可用性和统计评价必须保留在科学方法中。

规划或修改论文图表时同时阅读 [FIGURE_PLAN.md](FIGURE_PLAN.md)，保持图号、首次引用位置、图表分工和正文主次一致。
