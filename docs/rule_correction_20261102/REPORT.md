# 规则纠错机制与现有强制限制审计

日期：2026-11-02。用户要求将纠错机制写入全局与项目AGENTS，并检查是否还有未经验证的假设被写成强制限制。

## 结论与范围

已同步全局、工作区、第二篇AGENTS的七条纠错机制。第二篇AGENTS改为当前规则入口；旧全文完整保存，避免历史日期指令反复成为现行约束。检查了3层AGENTS、论文子目录AGENTS、第一篇refactor子目录AGENTS、两份错误预防文档、上层规则副本、当前执行政策、GHI路线与训练交接入口，并只读查看本机保存的自动任务状态。

本次发现不是“20条都需要放开”。下面20项分为：方法假设不应强制、已被用户新决定取代的旧限制、应继续执行的用户选择、应继续保留的数据底线。其中OOF等问题此前已修复，本次主要消除旧AGENTS中的残留与重新生效风险。没有审核全部历史脚本、所有会话或远端配置，不能据本报告宣称全项目再无规则问题。

```text
科学问题与当前主比较：

```

每轮完整比较结束检查一次；普通轮询不重复。发生旧新结果矛盾、辅助指标与GHI背离等情况，优先用现有模型/输出定位，避免盲目续训。没有强制四臂、OOF、全套多seed或额外审查通行证。正式结果仍保留原评价口径及负结果。
