# COT加入后为何变差：本轮原因检查

当前证据最值得优先验证的是**kt训练目标与GHI评价的权重不一致**，其次是**外推输入上的COT反演退化**和**四维统计压缩的表示限制**。尚未证明唯一因果原因，不能因为COT有物理意义就预设加入后必然改善，也不能把本次小头结果推广为COT无效。

本轮实际重读并SHA绑定全部8份已存validation预测、全部epoch记录和小型train/validation标签数组。共同99849验证行/真值核验通过，无test，无权重更新。完整可复算输出：`audits/cot_failure_causes_20260908_v1.json`；协议初版快照：`audits/cot_failure_causes_20260908_v1_protocol_snapshot.md`。追加的GPU实际训练残差检查被调度器拦住，未产生结果，见末节。

## 1. 已证实的目标不一致，尚待直接验证其因果影响

代码 `scripts/train_head_pilot.py:update` 优化：

\[
 L=\operatorname{mean}\left[w(\hat k_t-k_t)^2\right]
 =\operatorname{mean}\left[\frac{w}{G_{cs}^2}(\widehat{GHI}-GHI)^2\right].
\]

其中`w`按训练站点×lead均衡。相同w、相同GHI误差，晴空辐照度10 W/m²时的损失是500 W/m²时的2500倍。验证选模则是两站各自GHI RMSE的均值，没有这个逆平方因子。它符合现有已批准实现，并非本轮发现的除法代码bug，但可能让优化更关注低太阳高度下的大kt，而与目标GHI精度错开。

下表是**零预测参考损失**，仅度量标签和目标函数的敏感性，绝不是已训练模型实际loss或梯度占比：

|分支|Gcs<20训练行|占训练行|这些行占零预测加权kt损失|kt>100行|这些行占零预测损失|
|---|---:|---:|---:|---:|---:|
|original|30662|5.699%|95.689%|48|86.493%|
|QC1|30630|5.697%|81.246%|32|42.517%|

QC1仅隔离疑似平直段，没有消除这一目标敏感性。低Gcs、大kt不能直接认定标签错误或用于静默删样本；当前结果与原数据全部保留。

## 2. 误差并不是在所有条件下都变差

沿用原先按相同LR预算选定的A/AC，不重新选模。下表为同一区间的AC−A GHI RMSE，正值变差；按Gcs分组，**不是按实测GHI或天气分类**。区间指标在两站合并样本上计算，与论文候选的两站等权主终点不同。

|Gcs区间 W/m²|共同验证行|original RMSE变化|QC1 RMSE变化|
|---|---:|---:|---:|
|[0,20)|5672|−3.408|−0.271|
|[20,100)|7269|−6.789|+0.500|
|[100,300)|14049|−6.921|+3.701|
|[300,600)|21645|+0.376|+5.784|
|[600,+∞)|51214|+7.559|−0.137|

original在低/中Gcs区间改善、高Gcs区间明显退化，与目标权重错配假设相符；QC1的退化位置不同，说明不能只靠这一张表认定同一单因机制。按两站主终点，original四里+1.755、竺家+7.768 W/m²；QC1四里−0.392、竺家+3.077 W/m²。主要净退化来自竺家。

共同99849行的合并MSE增量中，original的偏差平方变化为117.125，中心化误差变化为1236.334 (W/m²)²；QC1分别为182.512和157.386。original的退化主要不是一个可用常数偏差修正消除的问题。中心化误差这里是残差围绕其均值的平方均值，不是“模型方差”的多种子估计。

## 3. 当前融合实现只用了四个数

`cache_frozen_forecast.py`从冻结R的log1p(COT)云场得到均值、空间标准差、p90和[8,8]中心像元。`Head.forward`把这4个值拼接在AGRI CNN池化特征后，交给MLP；没有把完整COT场输入空间编码器，没有辐射传输约束、可靠性门控或COT时序编码。p90/均值等无法完整保留云边缘、站点周围云的位置及运动结构，这是实现事实；它是否导致当前退化仍需要单变量、同预算对照，不能直接从信息压缩推导无收益原因。

A与AC网络结构、参数张量数量、seed、每epoch排列、batch2048、两档LR、最大50epoch和patience8相同；A将COT槽置零。AC可以在表示上将COT连接权重置零而退回A的函数族，但有限样本和当前优化不保证找到该解。当前COT来自同一AGRI的检索，不能当作新增独立观测，也不能把有物理意义等同于自动提升。

## 4. 输入域退化已被固定配对诊断证实，GHI因果链未闭合

既有同目标/同参考mask、相同冻结R的872配对诊断，COT RMSE真实AGRI输入4.293596，SimVP外推输入10.131402，约2.36倍。两站32个station×lead组均外推误差更高。这是已完成的有界CPP-reference证据，本轮未重复前向；CPP生成者仍未绑定，且R在validation选模等限制保留。它证明该抽样内外推输入上的检索退化，不单独证明GHI负收益由此造成。

本轮空间检查已通过的12行下游像元链，不等于此问题消失：对齐正确也可以存在外推图像统计/细节退化。具体见 `COT_PAIR_DIAGNOSTIC_RESULTS_20260908.md` 和 `COT_SPATIAL_REAUDIT_RESULTS_20260908.md`。
