# 在模型结果出现前冻结的 QC 敏感性 pilot

决定：条件放行两套成对探索性 A/AC pilot。QC-v1 是研究者根据源记录诊断制定的“疑似正值平直段”处理假设，不是官方认证的质量标准，也不是已经证实的传感器故障。原数据、缓存和标签保留；本决定不改变正式测试协议，不查看 test。

## 预先冻结的两套输入口径

- original：原有538053条train、99849条val。
- suspected-flatline-qc1：对源记录严格相等、有限正GHI、相邻区间末时刻差5min、连续至少12条（支撑60min）的段，隔离标签窗口中任一源记录涉及该段的站点目标。规则对两站和train/val统一执行，不按日期名单筛除；本次影响448条train、0条val，共28个站点目标。剩余537605条train、99849条val。排除键和原值写入独立CSV，旧pack不改。

60min之前只是诊断标记，本文件才将其升级为pilot处理规则；这是基于数据检查的探索性预注册，不能描述为独立盲态QC。所有非平直段低晴空分母引起的大kt保留；不设kt上界、不删整天、不换损失。小头规范化在该口径保留的train特征上重拟合；S/R及其归一化、forecast cache保持冻结。重新计算32个站点/lead组权重。

每套均A/AC×{3e-4,1e-3}×seed42，最多50epoch/patience8；共8次公平搜索。batch统一2048，架构、初始化、优化器、BF16/FP32/FP64分工沿用HEAD_PILOT_RUNBOOK。无论QC收益正负都完成并保留original分支，不根据先跑的结果更改任何后续参数。执行顺序预先固定QC-v1四次、original四次；每套分别按两站等权val GHI RMSE选各自LR，原始逐样本预测全部保存。

QC-v1先作新的8序列工程过拟合门（使用已测batch，数据形状及GPU内存规模不变）。original已有207615门禁通过。所有分支在同一99849条val键上报告，禁止选择更有利的cohort作为唯一结论。若COT增益依赖QC口径，则记录为观测质量敏感；pilot结果不是正式论文收益。后续正式QC/test口径仍需在test开放前冻结。
