# COT空间场方向把控

## 决策与边界

把完整COT场作为GHI网络的早期空间输入，而非只在末端拼接四统计量。首轮整图是当前完整16×16站点patch；扩展到256×256区域图是另一项尺度实验，尚未纳入。采用H14最小改动，S/R、GHI损失、标签、cohort固定，禁止同时引入ResNet/CBAM后把总收益归因COT。

科学主线：空间表示是否有价值 → 是否超出容量与CPP监督解释 → IFS是否额外改善。空间拼接本身不等于论文创新，必须完成最近邻方法比较和受控实验。旧四统计量多种子不稳定说明旧配置未通过，不证明COT无效，也不证明空间图更好。
