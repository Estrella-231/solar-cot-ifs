# 真实 AGRI 云图的 COT 反演改进试验

本试验仅使用湖南真实观测 AGRI patch（13 通道）及该目标时刻的三个逐像元确定性几何通道来训练和验证 COT 反演器。CPP COT 只作监督参考，不把 SimVP 预测图作为输入或选模数据；不读取 test。旧冻结 R 与此前的预测输入域适配权重保持不变。

原冻结 R 在 6,536 张真实 AGRI 验证图上，CPP 参考 COT RMSE 为 4.2465，厚云（CPP COT≥30）RMSE 为 11.9531、偏差为 −4.5513。先前的物理 COT SmoothL1 辅助损失未改善，因此本次只改变**训练像元权重**，检验原 log1p Huber 对厚云是否权重不足。两组从同一 R checkpoint 开始，使用相同 11,978 张真实 AGRI 训练图、6,536 张真实 AGRI 验证图、CPP 掩码、归一化、seed42、样本顺序、COTUNet、AdamW、FP32、batch256、学习率 1e-4 和 24 epochs。

- `log_control`：原有效像元 `log1p(COT)` Huber（delta=0.1）。
- `high_cloud_weighted`：相同 Huber，但训练像元权重固定为 `1 + 2·clip(CPP_COT/30, 0, 1)`；权重仅由训练标签计算，推理不需 CPP。

两支包括初始 epoch −1，均按同一验证集的物理 COT RMSE 选模；保留保存的逐像元预测，并同时报告整体、厚云、站点 5×5、晴空 RMSE 与厚云偏差。若整体或厚云未优于原 R，不替换冻结模型；即使改善，也先作为真实图像输入域的验证候选，不能推断 SimVP 输入域或 GHI 会改善。独立时间测试及 CPP 生产者来源核查仍是论文性能主张的前提。PBS 仅在实时确认全账户未结束任务少于 3 且总 GPU 数不超过 8 后提交。

## 实际结果

PBS `210251.tc6000` 单卡完成（exit 0，墙钟 1 分 44 秒）。使用相同的 6,536 张真实 AGRI 验证图和 1,664,013 个有效 CPP 像元；独立审计脚本核对三组保存预测的原始行号、CPP 真值和掩码，重新计算下表，无 test 输入。

| 真实 AGRI → CPP COT | 原冻结 R | 原损失继续训练（epoch 21） | 厚云加权（最佳仍为初始 epoch −1） |
|---|---:|---:|---:|
| 全像元 RMSE | 4.2465 | **4.1688** | 4.2462 |
| 全像元 MAE | 2.0323 | **2.0037** | 2.0323 |
| CPP COT≥30 RMSE | 11.9531 | **11.2890** | 11.9498 |
| CPP COT≥30 偏差 | −4.5513 | **−3.6772** | −4.5534 |
| 站点 5×5 RMSE | 3.9440 | **3.8819** | 3.9436 |
| CPP COT<0.1 RMSE | **0.7711** | 0.8474 | 0.7712 |
| 四里 / 竺家 RMSE | 4.6981 / 3.7488 | **4.6353 / 3.6515** | 4.6978 / 3.7485 |

因此原损失继续训练相对冻结 R，在真实 AGRI 上总体 RMSE 降 0.0777（1.83%）、厚云 RMSE 降 0.6642（5.56%），两站均改善；**晴空退化 0.0763（9.90%）**。厚云加权的单因素候选没有通过验证，不能把改善归因于新增厚云损失。改善来自在原损失下以更小 batch/较低学习率继续训练，尚不能区分步数、batch 和学习率各自贡献；旧 R 不覆盖。当前新权重仅是验证候选：服务器 `runs/cot_real_agri_highcloud_pilot_seed42_20260922/log_control/best.pt`，SHA-256 `18d285c2b1349ca9890c48109b3a149520638674bae69293ff9480938fcfe069`。

按验证月份拆分后，整体 RMSE 在 2025-07 为 3.9637→3.9444、2025-08 为 4.4125→4.2337，但 **2025-09 为 4.6483→4.7198（退化）**；三个自然月的厚云 RMSE 均改善，晴空 RMSE 均退化。这里的全部月份已经共同参与 epoch 选模，月份分解只是诊断，不是独立测试；不能称为跨时间稳定提升。原始逐月结果在 `results/cot_real_agri_20260922/month_decomposition.json`。

`figures/real_agri_cot_retrieval_cases_20260922/real_agri_cot_retrieval_cases.png` 用**真实目标 AGRI**做假彩色图，按四里站点中心 CPP COT 的晴空、中等、厚云三个预声明区间选取时间中位数样例；并排显示 CPP 参考、两版 R 输出及像元误差。选样不看模型误差，仍只能辅助解释：厚云单例的某些像元新 R 误差增大，与完整验证集厚云 RMSE 的平均改善可以同时成立。图像不含 SimVP 预测云图。
