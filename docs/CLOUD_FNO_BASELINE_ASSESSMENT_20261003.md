# Cloud-FNO 文献基线的可比性核查

日期：2026-10-03。状态：已阅读用户提供的11页PDF、核查图1/图2/表1，取得作者公开源码；未执行源码、未启动训练、未读取新test载荷。本报告不改变当前先完成新划分SimVP基线的顺序。

## 结论

Zhang等的Cloud-FNO适合作为**直接云物理场预测**的文献基线。它能与湖南SimVP→R链路作系统比较，但不是一个直接输出站点GHI的模型。最有价值的配套基线是论文中的Cloud-SimVP：把同类视频预测骨干直接训练在云物理序列上，帮助区分“预测表示不同”与“FNO骨干不同”。不把Cloud-SimVP混称为我们现有的AGRI-SimVP。

论文：Feng Zhang, Xin Hong, Zhijun Zhao, Zeyu Gan, Pengxiang Ouyang, Haixia Xiao, Renhe Zhang, Xujun Wei, Miao Cai, Feng Lu (2026). *Short-Term Forecasting of Cloud Physical Properties Based on Fourier Neural Operator Method*. Geophysical Research Letters 53, e2025GL119553. DOI [10.1029/2025GL119553](https://doi.org/10.1029/2025GL119553)。用户文件已本地读取，正文与出版社页面互相核对。

## 原文到底做了什么

| 项目 | 已核验设置 |
|---|---|
| 来源 | Himawari-8/AHI热红外观测经DaYu系列检索模型得到的全天云产品；不是直接输入原始多光谱图像 |
| 物理量 | CLP云相、CTH云顶高度、CER云有效粒径、COT云光学厚度 |
| 时空分辨率 | 30分钟，5 km；训练切片512×512 |
| 时间合同 | 历史3 h→未来3 h，再把预测作为输入递推到6 h；公开脚本为6帧输入→6帧输出 |
| 主体 | 四层3D傅里叶算子，包含频域变换/学习滤波/逆变换和局地线性路径；FCN编码和读出 |
| 原文任务 | CLP分类，CTH/CER/COT多任务回归；分类交叉熵、连续变量MSE |
| 数据划分 | 2016年3–12月训练，2017年测试；正文称逐月抽样训练、另1200条验证和逐月1200条测试 |
| 参考与评价 | 全天检索产品上的MAE/MBE/RMSE、PSNR/SSIM、CLP准确率；另与MODIS产品匹配比较 |
| GHI | 未进行我们所需的两站15分钟区间GHI收益评估 |

原文COT数字必须按参考来源分开：

- 对全天CPP检索产品的0–6 h平均RMSE为9.01、MAE为5.57；图2的+1至+6 h COT RMSE为6.75、8.09、8.93、9.61、10.16、10.54。
- 表1的MODIS配对参考下，Cloud-FNO COT RMSE为12.64，Cloud-SimVP为17.02，真实全天检索产品为11.84。“真实全天产品”本身仍是反演产品，与MODIS也有差异。
- 不能把其9.01或12.64与我们的四里站点RMSE8.60或+4 h RMSE10.33直接排名：卫星、区域、像元尺度、时效、云况、参考与空间汇总范围均不同。图2统计的是图像像元，我们前一轮主表是一个站点像元。

## 作者代码与复现缺口

论文给出[Zenodo概念DOI 10.5281/zenodo.17140340](https://doi.org/10.5281/zenodo.17140340)。API解析到版本记录17140341，本轮下载6个小型Python源文件并记录SHA256：`results/literature_fno_cpp_20261003/author_code/source_manifest.json`。没有下载或执行模型权重；没有把作者数据用于湖南训练。

已确认：

- `CP_6h_512_cloud_LP.py`包含`FNO3d`和`SpectralConv3d`、四层谱卷积及1×1×1路径；默认modes=6、width=24、6输入/6输出、512空间格。
- 文件名和训练代码对应云相分类；末层3分类，标签one-hot、CrossEntropy。不能据此声称已取得正文完整CLP+CTH/CER/COT联合训练器。
- 该脚本包含硬编码私有数据路径与接续加载checkpoint；公开文件列表没有这些权重。它不是开箱即用的湖南训练入口。
- 部分实现与正文不完全一致：脚本学习率1e-5而正文1e-3；源码谱层激活写法与正文后两层ReLU不同。需要补充材料/作者确认后才能称严格原文复现。
- 作者实现也将历史帧放入特征槽，再沿输出时间维复制，FNO在空间/输出时间体上变换。因此不能以“历史堆成通道”一个事实认定它没有利用历史，也不能声称它天然进行了云对象轨迹追踪。历史表示是否有效要用对照验证。
- `pred_6h_cp.py`展示预测前6步再递推后6步。新代码不得在第二段输入真实未来产品。

源码仅作为模型结构证据，导入其原训练入口会触发训练/路径/设备设置，故本轮只读文件未导入。

## 推荐的最小对照矩阵

第一阶段所有直接COT预测臂都使用**同一个新日期合同下独立训练并冻结的R**，从真实历史AGRI生成同一套历史COT场；未来监督及其掩膜完全相同。先不混入CTH/CER/CLP，避免把多变量输入优势归因于FNO。

| 对照 | 部署链路 | 能回答什么 |
|---|---|---|
| 末帧持续性 | 历史AGRI→R→最后一张COT保持不变 | 最低复杂度参照 |
| 物理输运 | 历史AGRI估计运动，搬运历史COT | 运动本身能做到多少；现有常量平移不等于完整稠密光流 |
| 现有AGRI-SimVP→R | 历史AGRI→未来AGRI→同一R | 当前系统参照 |
| COT-SimVP | 同一历史COT序列→未来COT | 改为物理表示后，普通时序骨干能否已经有效 |
| COT-FNO | 同一历史COT序列→未来COT | 在相同物理表示下，傅里叶算子是否有额外价值 |

后两者均为**湖南COT-only适配版**，不能写作原文四属性Cloud-FNO的完整复现。矩阵的两层归因不能混淆：

1. COT-SimVP与AGRI-SimVP→R属于系统/表示路线比较，预测目标、损失与参数需求不同；不能把差值全部说成架构优势。
2. COT-FNO与COT-SimVP应共享相同历史COT、标签、掩膜、样本、归一化合同和选模口径，报告参数量与实际更新预算，才能评价物理域预测骨干。控制规模与同等调参预算，不能以某臂只训练极少更新来制造优势。

如果要再接近原文，另建CPP-FNO与CPP-SimVP，**两臂都**使用CLP/CTH/CER/COT历史输入和多任务监督。前提是四属性产品语义、单位、来源、可用性及掩膜已验收；当前仅有COT反演器不等于已有可信四属性推理链。该组单列输入信息和容量，不与COT-only组直接归因比较。

## 湖南适配合同

- 按2026-10-02新按月连续日期块合同重建train/val，归一化仅用新train。所有learned基线随机初始化，不拿旧权重进入新独立test。当前先完成新AGRI-SimVP基线；不抢先用旧R/H评新test。
- 主合同仍是8张历史、15分钟间隔、256×256湖南区域、未来16张。建议COT模型每次预测8张，第二次只用第一段预测递推到16张；须实测是否适合该模型，不能称与原文6→6/30分钟完全相同。
- 原文512×512对应5 km像元；我们的256×256具有不同物理视场。须记录真实湖南网格尺度，不能简单上采样到512就声称复现。FNO具有可变网格的设计也不保证换分辨率后的精度不变。
- COT参考可采用未来CPP，若用未来真实AGRI→R则明确为代理监督；所有学习臂必须同源。未来真实产品只作监督，不作部署输入。
- 缺CPP只关闭监督/评价掩膜，不填为晴空，不缩小正式GHI cohort。单独报告COT参考覆盖，所有COT方法在共同有效区域比较，另给完整预报覆盖，避免范围缺失偏袒某臂。
- 先按16lead报告站点像元和64×64逐像元RMSE/MAE/bias、COT≥30厚云、边界/到达误差；空间场不是全图均值/p90特征。图像评价与站点评价单列。

## 怎样接到我们的GHI论文

Cloud-FNO只解决E（未来云物理状态）部分。若其COT更好，仍须以相同AGRI条件、太阳几何、样本及相同H架构和优化预算训练对应GHI头，比较无COT、AGRI-SimVP→R、COT-SimVP、COT-FNO；先不加IFS。H对各预测来源分别在新train拟合，在新val选模。

固定旧H直接换成FNO预测只能作输入敏感性/OOD诊断，不能作为公平GHI排名。只有COT质量和GHI收益都验收，才把这一路线列为有效基线或贡献；不能把原文未验证的GHI提升写成已有结论。

## 其他文献基线的优先级

- **SolarSTEPS**，Carpentieri等，Applied Energy 351 (2023),121775，DOI10.1016/j.apenergy.2023.121775：直接在晴空指数场上做分尺度平流/自回归/概率预测。适合作概率/演变参照，但它原本预测CSI而非COT。若移植到COT须标适配版，CRPS与确定性RMSE分开，不把概率改善冒充均值预报改善。
- **HelioNet**，Straub等，Solar RRL 8 (2024),2400475，[全文](https://onlinelibrary.wiley.com/doi/10.1002/solr.202400475)：历史云指数→未来云指数→GHI，适合另一条辐射表示参照。CI不等于COT，湖南需要先定义并验收云指数/辐射映射，不能直接把COT改名为CI。
- 本轮优先只准备Cloud-FNO、同输入COT-SimVP与运动参照的协议，不因文献名字多而同时开新模型。没有新训练提交或监控授权变化。
