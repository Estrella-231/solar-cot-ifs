# 固定GHI头对COT的局部响应

承接已完成来源替换：米庄12个开发日期中10天退化，去掉任一天仍增加0.404—0.968 W/m²。参考中心COT增加超过3的495条共同记录，三个seed平均GHI分别上调2.174/2.167/3.805；中心COT减少超过3的426条则下调。这是联合3×3来源替换的关联，不能当单像元偏导或普遍物理规律。

本步固定所有GHI权重、G1输出、AGRI、历史、太阳几何及mask，仅计算当前large_future_COT头对未来log1p(COT)的输入导数。目标槽和相对最后历史差值槽按原公式同时变化；历史无效时差值槽保持0。逐中心像元及9像元同向变化分别计算，不混为同一响应。

读取既有large C_fit日期和C_select，保持原行，拟合域与选模域分别报告。使用原G1重建基底并与已保存C_select逐样本预测核对（GHI容差1e−3）。条件头在double下算输入梯度，参数requires_grad=False且不建优化器。以logCOT±1e−5中心差分检查中心/9像元方向，误差容差1e−5+1e−4×|导数|；不能放宽失败门槛。共同太阳mask无效时输出精确G1、导数0。

保存逐样本键、基底与修正预测、中心和9像元方向导数、行角色、残差、物理COT。方向分数仅描述：正导数不自动等于物理错误，GHI含散射、AGRI/COT共线且该导数是固定AGRI的条件响应。不能由此强加整体单调规则或声称找到唯一根因。

不重新选模，不扫描扰动大小、门控阈值、正则系数，不读official val、新时段、outerbuffer/test。GPU仅短前向和输入梯度；三站各一卡并行，核对PBS≤3/GPU≤8。按已核验swc环境运行，不重装。完成后决定是否具备提出单因素训练假设的依据；本次本身不是预报收益。
