# 连续观测参考的反演与评分细则

执行前补充于既有DENSE_OBSERVED_R_REFERENCE_PLAN。CPU提取已完成4,025个V时刻，未生成密集R输出或相应指标。本细则不改变模型、阈值、日期或既有CPP评分。

1. 完整下载CPU pack，逐文件核对complete.json中的x_raw/mask/rows SHA，并再次核验3140条V序列及support/hash/date成员。R_U第50轮权重、U归一化、R结构源码和修正几何均绑定旧因果推理manifest。
2. 使用本地冻结R、torch.float32、eval/inference_mode、批128，不使用autocast，记录CuDNN/TF32实际设置。网络输出为log1p(COT)，只expm1一次，不裁剪有效预测来改善指标。归一化只使用原U值，不重新拟合。
3. 仅当某张16×16图至少一个像元通过既定QA和SOZ<80°掩膜时才调用R。完全无支持的夜间/无效图不进入反演，输出NaN且mask=false；有支持图的无效像元同样输出NaN。它们不是晴空0，更不是夜间COT真值。不改变有效像元，所有方法在同一掩膜评分；有效像元非有限或负COT则直接报错。
4. 对原1,398张稀疏参考的可匹配行，另列原值和新参考差异。三时刻试读已表明AGRI一致而R结果有小幅差别，故不把两版本混为完全相同，也不替换旧评分。比较修正几何、无效通道归零和批次的数值差；以来源检查和差异记录为准，不用漂移反推预测收益。
5. 在全部V预测上以密集R为离线教师参考，报告center/3×3/16×16逐时效与分站RMSE/MAE/bias、COT≥30的POD/FAR/CSI。它衡量预测对教师的保真度，不是CPP精度或GHI收益。与之前CPP共同支持表完全分开。
6. 连续事件、缺测、截断、固定完整窗口、日窗口选择、峰值并列处理，逐项复用COT_EVENT_TIMING_DIAGNOSTIC_PLAN。所有方法共用一个事件窗口，漏报、预测左截断和可算到达误差的数量同时报告。R识别出的事件只称R参考事件，不冒充独立物理真值。
7. 固定日窗口依然每站每天最早完整16帧；保留其上午偏重限制。每站展示一个P-XC中心峰值绝对误差最大的日窗口，注明事后选择；此外展示所有可评价事件或完整CSV，不仅展示双检出的好例子。不得用事后最佳时移替换原始逐像元分数。
8. 不读GHI，不进行GHI重训/重评分，不读取旧test/buffer；真实未来图仅离线参考。结果用于提出可证伪的下一机制假设，不能绕过已关闭的H/V融合搜索或未使用数据确认要求。新湖北文件的单位与时间确认单独等待，不与湖南混用。
