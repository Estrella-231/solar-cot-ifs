# 已冻结反演教师与未来COT预测的误差分解

状态：执行前固定，2026-10-21。承接原方案6.1中尚未完成的“相对R_U教师另列”诊断；不增加训练或改变H/V上的融合参数。

问题：直接未来COT接入GHI未产生稳健收益，究竟是预测器丢失了教师中的厚云信息，还是当前U-only反演教师自身对CPP参考存在明显误差？只分析已经参与开发的V及其归档CPP支持，不能称独立确认。

固定来源：同一U-only R_U第50轮权重和U归一化、原归档CPP pack的SUPERVISED/val行、湖南grid_static及冻结修正几何、已保存且来源隔离的V预测。从既有x_raw中只提取上述val行，重算几何后获得“真实未来AGRI→冻结R_U”的参考图。真实未来AGRI只进入这一离线反演参考，不送给P、SimVP或GHI，不重训头、不改变可部署输入。CPP只作检索参考。

在相同station/init/target/lead与像元支持上分别报告：R_U真实图反演对CPP、四组因果COT预测对CPP、四组预测对R_U的RMSE/MAE/bias、厚云POD/FAR/CSI、幅度离散度与相关。两种掩膜分别记录：原CPP归档支持（用于复现旧评分）与其交集修正几何SOZ<80°支持（用于本次分解）；不得将本次掩膜下的新数值替换旧成绩。16×16、3×3、中心及每站每时效均完整报告。

对每组F按逐像元恒等式分解：

`(F−CPP)^2 = (R_obs−CPP)^2 + (F−R_obs)^2 + 2(R_obs−CPP)(F−R_obs)`。

这是代数误差分解，交叉项可正可负，各项不能解释为独立因果贡献率。比较R_obs与预测组的RMSE差，用原固定26个月度连续两日块、5000次配对bootstrap（seed20261020）、两站等权；缺CPP块保留为空并报告覆盖。预测重叠窗口不作独立样本。

在同一1398行上复核FP32与原训练教师缓存所用FP16的差异，避免把数值精度影响当成预测误差。禁止根据结果调整阈值、掩膜、checkpoint、损失或训练预算。

地图按预设解释性规则选择：每站“预测相对教师误差最大”与“教师相对CPP误差最大”各一例，标明事后案例，显示真实C03、CPP、真实图反演R_U、P-XC、SimVP→R_U、持续COT，并标同一站点像元。像元原分辨率、不插值、同COT色标；超范围与无效像元显式记录。图仅解释错误，不估计总体收益。
