# 生成速度诊断与8卡续跑

实测：batch2稳定吞吐0.550序列/秒/卡，batch8为0.560，提升1.9%；峰值reserved分别3.707和14.262GiB。batch16单批峰值27.275GiB，仅有含初始化的一批，不能当稳定吞吐；其AGRI输出最大差0.7142，未选用。batch8 AGRI和几何与batch2逐值一致；R的log1p(COT)最大差0.001689，对应物理COT最大差0.03321，属于浮点批形状差异，保留数值记录。
