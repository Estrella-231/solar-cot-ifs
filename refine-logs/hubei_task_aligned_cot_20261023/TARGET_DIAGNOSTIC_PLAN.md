# 校正目标与G1实际残差的匹配诊断

在215819完成且负结果封存后进行的事后归因，不是预先主实验，不训练、不改权重或系数。只复用large C_fit及原三折，test/C_select/新时段不读取。

先问：即使未来九像元COT精确等于同R实际图反演参考，冻结教师的创新响应delta_ref=sum(s*(logCOT_ref-logCOT_raw))，加到G1上是否能够降低GHI误差？这仍是不可部署的离线输入，不叫COT真值上限。

比较原G1、上述精确参考创新、physical/task实际创新及direct_AGRI残差。每个模型分别计算原拟合日期与自己的日期留出折，归一化、available沿用原实现。实际参考不进入任何部署分支。拟合日期跨外折重复，因此fit只做逐模型汇总，不把重复记录当独立样本，也不与OOF总体RMSE混合。

保存每个站点/基底/外折/域的RMSE/MAE/bias、模型训练目标分量、COT误差，以及e=G1-y、delta的2e*delta与delta²、纠错方向率和幅值。用DeltaMSE=mean(2e*delta)+mean(delta²)独立复算。报告delta_ref与所需残差y-G1的相关/无截距投影系数仅用于描述，不拟合新部署缩放、不扫描或重选幅度。零残差/零创新不算正确修正。完整OOF保持所有原行；无效行delta=0。

若精确参考创新本身失败，则否定“只要学到该教师的COT变化即可改善G1”的充分性；不能据此否定真实COT信息价值。若fit改善而heldout失败，则提示跨日期泛化限制；仍不能独归因某种天气或站点数据质量。81个checkpoint均保持不变，任何后续新候选须另行固定方案。
