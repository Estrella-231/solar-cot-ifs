# 现有预报厚云分层与连续事件分析

图示取帧说明：初版采用峰前30分钟、参考峰值、峰后30分钟；检查发现不能展示长时效消散/恢复，最终统一为峰前30分钟、参考峰值、该起报最后一个有效GHI目标时刻。仅是所有案例一致的显示规则，未按误差大小挑帧；事件、起报和统计未变，原先导出的完整16帧数据无需重取。

2026-11-02，用户授权。仅分析已有真实图训练冻结头的湖南66,086、湖北24,451条预报验证记录，不训练模型、不改变总体评价掩膜、不读test/buffer。统计使用analyze-results，图件使用scientific-visualization；论文用图为一般180 mm宽预览，尚未针对特定期刊提交规范。

1. 主分层取目标时刻、站点像元、质量有效的CPP参考：近零[0,0.1)、薄[0.1,5)、中等[5,30)、厚[30,100]；与当前同期分析一致。缺参考为Unknown，保留在总体。CPP是检索参考而非独立真值，目标时刻分类只用于离线评价。
2. 主指标沿用各站各seed先计算再等权的GHI RMSE/MAE/Bias。报告样本、不同站点目标时刻、日期和厚云连续段数；全时效、+15～30、+45～240及逐lead分别保存。COT RMSE/Bias及厚云POD/FAR/CSI在对应CPP有效支持单列，不作GHI通行条件。
3. 不同初始化保留原预报记录；同站同目标时刻参考及观测必须一致。连续厚云段按同站相邻15分钟且CPP≥30连接，缺测/薄云/日期间断均断开；单时刻段保留并标记。这里是站点厚云连续段，不声称跨站独立云对象。日期块bootstrap保留所有相关起报记录，额外做逐日期删除和目标时刻等权敏感性。
4. 个例条件事前固定：优先每省改善/退化各1个，最多4个。先要求至少两个相邻厚云参考时刻，再在每类中按日期最早选择；若不足，明确记录放宽到单参考时刻，不制造事件。改善/退化按事件目标时刻等权的有无COT平方误差差判定，仅为条件选例，不估计收益发生率。选择起报/画图帧时不按误差大小筛选。
5. 用同一次起报展示完整15分钟GHI曲线，固定seed42作说明，其他seed结论另表。AGRI合成固定C03/C02/C01及全局平方根映射[0,1]；原生16×16、站点和3×3位置标注。参考CPP、真实图R与预测R使用同色标且缺口保留；真实未来只作离线图示。优先选峰值前/峰值/峰值后，所有源图真实存在后才绘制。
6. 不预设厚云一定改善，不以挑选成功个例替代总体。原CPP覆盖有限；当前结果不外推为所有厚云和独立测试表现。先输出分析、图、案例源数据与建议放置位置，之后再决定正文整合，不先修改论文。
