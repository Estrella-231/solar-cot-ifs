# 方向约束减少了修改次数，但未消除薄云误加厚，未进入GHI

## 比较的问题及范围

上一轮发现原预测COT残差大范围向上。F_fit独立日期探针说明部分修正方向可辨识，因此本轮固定残差网络与预算，只限制允许的修正方向：保持时严格回原COT，上调只允许非负残差，下调只允许非正残差。没有按F_select重选类别阈值。

残差网络仍34输入、7249参数；外部方向分支另有921个线性系数，不将残差网络同容量说成全系统没有增加辅助模型。F_fit方向由日期±1日隔离的OOF探针产生，F_select方向仅由完整F_fit拟合的固定规则分类器产生。全部103948个站点OOF方向与16×16滑窗结果完全一致；边界一圈/太阳缺效不修正。

新旧使用同一归一化、相同初始化/采样顺序、global batch128、600更新、AdamW/cosine及step0可选。44531候选F_fit场中892场没有有效监督，实际训练43639场，新旧一致，非数据缺失。F_select2528场、12目标日期、6026共同有效站点记录；指标为逐站逐15min时效RMSE再48组等权，三seed分别算后平均。参考为同折R真实图反演，非CPP独立真值；这是已使用开发日期，不是独立测试。

## 为什么方向分类分数不错，厚度仍未改善

方向限制已确实执行：保持输出逐位等于原预测，缺效为0占位，允许方向无违反；不应继续把失败归因于门控没有生效。

方向分类从F_fit OOF转到F_select后，“需上调”精确率在牛首/王寨/米庄为42.46%/44.44%/52.68%，“保持”精确率约80%—83%，低于F_fit OOF约92%。这仍是开发范围的描述，不能据此调阈值。

|---|---:|---:|---:|
|原预测RMSE|2.880|2.689|3.280|
|方向约束后RMSE（三seed先算后平均）|4.287|4.148|4.453|

约91%的近零记录保持不变，但少量错误修正仍足够大，使该组平均平方误差增加约9—10 COT²。不是必须频繁改错才会退化。参考COT1—10组也仍退化：牛首4.415→5.904、王寨4.320→5.722、米庄3.882→5.159；厚云≥30则继续有点估计改善，但不足以抵消上述限制并通过日期与虚警条件。

ROUTE_DIAGNOSIS.json保存完整路线/厚度分层与ΔMSE=2ed+d²复算（最大恒等式误差2.84e−14），没有据个例或正向子群替代全体。新证据说明“限制符号”不能单独解决误判与幅度问题，也不能把方向可辨识性直接转换成GHI收益。
