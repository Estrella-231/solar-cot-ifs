# COT-aware SimVP 单因素实验协议

日期：2026-10-17。用途：推进 COT 预报证据，不制作汇总图，不改变论文已冻结的 SimVP→R 结果或同期 GHI 主实验。

## 主张与边界

**待检验假设：** 在 SimVP 的 13 通道 AGRI 外推损失之外，增加冻结反演器 R 的 COT 辅助损失，可使预测云图保留更多验证集 CPP 参考所指示的云厚度信息，而不明显损害 AGRI 外推。

这不是已成立的论文主张。CPP 是稀疏检索参考；R 是 AGRI 派生反演器；事件结果仅来自3个北京时间日期。即使 COT 验证改善，也不能直接推出 GHI 预报收益或独立测试泛化。该方法是对固定 SimVP 训练目标的独立候选，不回写已发表/主表基线、既有 checkpoint、结果目录或正式 test。

## 实验块

### M1 同预算配对筛选（单种子）

- **对照：** 已完成的原始 AGRI-MSE 微调（同一新月度 split、初始化 checkpoint、训练样本顺序、seed 42、batch 8、4,000 次更新、优化器和学习率调度）。
- **候选：** 完全相同，只增加一项站点局地 COT 损失；不加新通道、不改 SimVP、采样器、AGRI损失或训练预算。
- **反演器：** 使用当前月度 R 固定参数；必须 `eval()` 且参数 `requires_grad=False`，但允许梯度从 R 输出穿过 R 回到 SimVP 预测 AGRI。对预测物理 AGRI 采用 SimVP 训练集归一化的精确逆变换；按每帧真实站点行列位置裁 16×16；拼接目标帧 `cosSOZ/cosRAA/day_mask`；使用 R 自己的 train-only 均值/标准差和 FP32 R 前向。
- **训练目标：** 两站的当前训练序列及16个目标时效。CPP有效像元使用精确键对应的 CPP 物理 COT；其他 R 有效像元使用相同目标真实 AGRI 经冻结 R 得到的 `log1p(COT)`，只作为扩充训练监督。两者分别记录标签来源；损失统一在 `log1p(COT)` 域，采用有限值安全掩膜平均。主 AGRI 损失仍覆盖原有全部有效 256×256 目标像元。
- **损失权重：** 只用训练日期中固定、按月份轮转抽取的32个窗口，计算 SimVP 输出处的 AGRI 与 COT 损失梯度范数比；预先定义 `lambda_COT = 0.1 × median(||grad L_AGRI|| / ||grad L_COT||)`，保存各批记录后冻结。禁止查看验证结果后调权重。
- **主终点：** 当前 CPP 共同支持上的物理 COT RMSE，分别报告16时效和3×3站点局地；总体分数采用站点×时效宏平均，并在同一支持上与原 SimVP、MSE微调比较。厚云 CSI（COT≥30）、近零层虚警、偏差和MAE为护栏/次指标。
- **AGRI护栏：** 使用与既有 MSE 对照完全相同的全域有效像元、季节等权 RMSE 和 lead/channel 指标。若季节等权 AGRI RMSE 相对 MSE 对照恶化超过1%，或厚云 CSI下降超过0.02，或低COT(<1)虚警显著增加，则不进入论文正向结论。
- **验收：** 保存逐样本预测并独立FP64复算；关键 COT RMSE 相对两条固定参照均需改善，目标日期块配对95%区间上界小于0，且所有护栏通过，才允许增加 seed 43/44。单seed筛选不单独形成稳定提升主张。失败则保留负结果，不进行验证集调参。
- **禁止：** 不读取 test payload；不训练或挑选 GHI 头；不把事件或 CPP 指标说成物理真值；不把真实未来 AGRI 输入部署预测；不改原 MSE 结果。

## 依赖与启动门

1. 将固定训练行清单、CPP序列包、R目标银行与R逐帧 sidecar 逐键核验；训练与验证严格分开，目标时间应与序列16帧一一对应，站点坐标绑定每个帧键。
2. 运行CPU合成见证：损失掩膜/NaN安全、坐标裁剪、冻结R梯度回传、R权重梯度为空、预测AGRI梯度有限且非零、标签混合规则。
3. 在指定服务器激活 `swc`，核验脚本/模型/数据与checkpoint哈希；读取PBS全账户队列。当前快照为2个未结束作业，尚余1个名额；node21仅有1张A100经PBS分配，不能把同节点其他用户GPU的空闲显存当成本任务资源。
4. 单卡实数profile须测完整前向、反向、峰值显存和samples/s，保留至少15%显存余量；profile达标后才运行4,000更新候选。qsub之前重新查全队列，并确认作业分配GPU、数据本地缓存及剩余磁盘。
