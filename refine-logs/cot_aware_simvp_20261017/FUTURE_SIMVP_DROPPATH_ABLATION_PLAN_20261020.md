# Future SimVP DropPath ablation

**Question.** Does the current SimVP stochastic DropPath regularization reduce useful forecast detail enough to suppress the downstream value of forecast-derived COT?

## Evidence motivating the single-factor test

The frozen baseline has no Gaussian/input-noise augmentation; its SimVP `drop_path_prob` is 0.1. A source audit of the exact candidate snapshot also found no crop, flip, rotation, jitter, blur, or additive-noise augmentation in `HunanDataset`; images are train-normalized and invalid pixels zero-filled. MLP dropout is configured as `drop=0.0`, leaving DropPath as the explicit stochastic regularizer under test; random sample shuffling changes order, not image values. On the validation station neighborhoods, predicted AGRI spread is about 4–5% below the observed-frame spread, and local predicted-AGRI error co-varies with absolute forecast-COT retrieval error (Pearson r=0.306 at Sili, 0.443 at Zhujia). These are descriptive clues, not proof that DropPath is causal. Temporal phase, adjacent-frame averaging, and input-conditioned COT gating did not establish an additional GHI gain. A single-factor `0.1 -> 0.0` DropPath test is now the smallest direct test of the remaining stochastic-regularization hypothesis.

## Frozen comparison

- Baseline: existing five date-held-out OOF SimVP forecast bank and its corresponding validation full-train forecast, `drop_path_prob=0.1`.
- Candidate: independently trained SimVP with only `drop_path_prob=0.0` changed. Preserve architecture, 8-to-16 framing, 13 AGRI targets, solar geometry, data and masks, train-only normalization, random initialization, seeds, fixed 12-epoch schedule, global batch 20, optimizer/schedule, and checkpoint rules.
- Train five OOF folds on the existing date-block manifests. Each fold's training loader reads only its train dates; the epoch-12 checkpoint is used without heldout-fold selection. Then fit a separate full-train candidate using the same full-train model-selection rule as the baseline to create validation forecasts.
- Apply the same frozen R, fit the same train-only COT calibration protocol anew on candidate OOF outputs, and rebuild the causal GHI head pack. Training heads use candidate OOF forecasts; validation heads use candidate full-train forecasts. No future observed AGRI, CPP, test, or buffer data may enter inference.
- Train the same three GHI-head seeds and fixed arms used by the ACREL screening, with identical rows, labels, masks, order, optimizer, epochs, and selection rules. The primary comparison is candidate ACREL versus baseline ACREL on exact common validation keys.

## Decision criteria

The candidate advances only if the paired target-BJT-date-block 95% interval for candidate-minus-baseline ACREL GHI RMSE is wholly below zero, neither station's point difference is positive, and the equal-station +15–60 min difference is nonpositive. Also report same-key AGRI and frozen-R COT metrics, per-channel/spread diagnostics, and all station/lead bands. If it fails, retain the baseline; do not tune DropPath on the same validation set.
