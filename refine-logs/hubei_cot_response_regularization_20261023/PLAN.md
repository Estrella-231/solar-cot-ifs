# 单因素候选：限制未来COT支路的正向局部响应

## 假设与既有工作区别

当前固定GHI头在米庄的拟合域就普遍具有正向整体COT导数，参考源改善后并未有效纠错。新候选检验能否抑制该条件捷径，而非继续重训外推、扫描COT方向阈值或扩大头。

旧CMF是固定物理特征编码，日期中心化改变残差监督，日期覆盖改变拟合日期，无约束/方向COT校正器改变COT源，当前候选仅在GHI训练损失增加输入响应正则。网络、输入、COT源及GHI监督都不变。已查当前refine-logs/docs未发现相同GHI输入梯度正则实验；不把它宣称研究新颖性。

## 配对训练与唯一变化

复用large C_fit的50/49/50日期、原C_select12日期和冻结G1；同9922参数ConditionalHead，未来AGRI/历史/太阳/mask/归一化均保持。三seed42/43/44、global batch1536、60更新、原采样顺序、初始权重、AdamW及cosine逐位复用calibration_coverage。epoch0参与选模，缺效精确回G1。

从相同初始化重放以下三臂：同容量无未来COT、未来COT原损失、未来COT加响应正则。两旧臂必须复现既有逐步损失及最终选模预测（1e−3 W/m²），否则先定位实现差异，不解释正则结果。无COT梯度应恒0，故不单独新增无COT正则第四次拟合；用同一输入下正则值/参数梯度严格0核验此等价性。

原损失为batch平均((pred_kt×clear−GHI)/1000)^2。新增项为：

`Omega = mean_batch[ relu( d pred_kt / d epsilon )^2 ]`，

其中每个有效未来COT像元同时满足`log1p(COT_p) -> log1p(COT_p)+epsilon`；相对最后历史差值槽同步变化，历史无效则差值保持零。保持所有AGRI/历史/几何和base标量固定。缺效回退行的导数与惩罚均为0，batch分母仍与原损失相同，不按天气删样。

唯一新loss为`L_original + 1.0 * Omega`；1.0是预先固定的无量纲候选系数，只测试这一值，不在原开发集扫描。该惩罚约束9像元同向变化的方向，允许各像元局地差异，也不约束基于AGRI/历史的上下调。它仍可能抑制真实散射增亮，因此必须报告失败情景，不能写成普适辐射定律。

## 执行前工程核验

在训练前固定合成与真实小批：解析输入梯度对中心有限差分；二阶梯度非零且数值有限；无COT惩罚和参数梯度0；零支路初始函数同G1；不可用行严格回退；两步断点恢复重放优化器/调度/global step/采样一致。二阶梯度只涉及小头，S/R/G1参数冻结。短任务按站点/seed并行，不改变每模型batch及60更新预算；若实测数小时则按根规则2/4卡吞吐选择。沿用swc，不装环境。

## 判据与停止

本次仅开发筛选：主比较正则未来COT−无未来COT，其次正则−原未来COT、−G1。逐站逐seedRMSE/MAE/bias、全部16时效和四小时组、5000次目标日期簇配对CI，保存逐样本物理预测、loss主项/正则项/梯度统计及best/last。先固定完整数据，不按收益删除站点、日期或时效。

继续要求主差值小于0且日期CI完全低于0；三站均不超过1% RMSE退化、至少2/3种子方向一致。高GHI≥800组作为既有诊断保护，样本数和偏差必须完整报告，若相对同容量无未来COT的绝对bias增加超过5 W/m²则不通过。输入响应下降本身不算成功。任何条件失败封存此系数/方法，不继续扫系数、修正幅度或选模范围。
