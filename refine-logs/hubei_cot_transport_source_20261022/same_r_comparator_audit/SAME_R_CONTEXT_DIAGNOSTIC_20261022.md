# 同一 COT 反演器下的未来 AGRI→COT 对照

**状态：验证集上下文诊断完成；非配对 SimVP 训练臂；不是 GHI 结果。**

## 这个比较回答什么

在现有 G1S 站点邻域 COT 预测验证样本中，把 attempt12 的 SimVP 预测 AGRI 输入与 COT 预测链相同的冻结反演器 R，比较 `SimVP 预测 AGRI → R`、学习得到的未来 COT 以及历史 COT 持平基线。这样可检查两种不同的未来 COT 来源在共同样本上的表现。CPP 仅作卫星反演参考，不能视为独立地面真值。

该比较不能证明 COT 提升或损害 GHI 预报，也不能证明底图外推是误差的唯一原因。SimVP 对照来自 attempt12（14轮、验证 AGRI 损失选模），并非 attempt13 的配对 MSE 控制臂；因此它只提供上下文，不是单因素模型比较。

## 支持与评价口径

- 区域和空间范围：湖北牛首、王寨、米庄三个站点中心像元；底层数据来自已批准的 16×16 站点邻域 COT 分支，不是 256×256 全区域模型。
- 共同支持：1,824 个 `(init_time, target_time, lead)` 窗口，5,460 条站点中心记录，覆盖 16 个 BJT 目标日期以及 +15 至 +240 min 的全部 16 个时效。条件为 CPP 参考目标有效且初始化时历史 COT 有效。
- 原 G1S 有效评分支持为 3,220 个窗口；共同支持只覆盖其中 56.6%（其余 1,396 个窗口缺少可用的 attempt12 SimVP 预测），不能把这里的分数写成完整 G1S 支持结果。
- 总体数值先在每个站点×时效单元内汇总所有日期，再对非空站点×时效单元等权平均。区间以目标日期为块做 5,000 次配对 bootstrap，种子 20261022。重叠窗口不是独立天气事件。
- 三种方法严格使用相同共同支持；数值来自保存的逐样本记录，并由独立 FP64 脚本重算。

## 结果

| 共同支持上的 COT 来源 | RMSE | MAE | Bias |
|---|---:|---:|---:|
| 学习得到的未来 COT | 13.871 | 9.578 | −0.318 |
| 历史 COT 持平 | 16.097 | 9.505 | +7.545 |
| attempt12 预测 AGRI → 同一冻结 R | 16.567 | 9.931 | +6.843 |

未来 COT 的 RMSE 点估计较历史持平低 2.226，较预测 AGRI→R 低 2.696。但配对日期块 95% 区间分别为 `[-2.952, +7.636]` 与 `[-6.280, +9.858]`，均跨零；MAE 也没有优于历史持平。因此，只能说该共同支持上的 RMSE 点估计偏向未来 COT，不能认定总体 COT 技能增益。

按 CPP 参考厚度分层后，最明显的短板是厚云：COT≥30 时，未来 COT RMSE 为 23.415，历史持平为 18.551，预测 AGRI→R 为 11.420；未来 COT 的厚云 bias 为 −22.477。近零、薄云和中等厚度组的未来 COT RMSE 点估计较低，但分层结果仍是 CPP 参考条件下的验证诊断，且不取代总体日期块区间。

## 决策

G1S 的预定 COT 门槛仍未通过：共同支持上的日期块区间跨零，CPP 厚云明显低估；GHI 配对训练不启动、不扩种子。湖北全区域路线仍须先恢复 FD-201 的只读 CPP 来源通路，并通过时间、网格和质量字段审计。配置中的正确别名 `FD-201` 本轮在 SSH key exchange 阶段被远端关闭；这是访问通路问题，不代表 CPP 数据缺失。
