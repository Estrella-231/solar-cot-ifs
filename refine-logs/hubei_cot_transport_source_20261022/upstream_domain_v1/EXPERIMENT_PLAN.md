# 湖北上游来源范围诊断：无需训练

2026-10-22 用户批准执行。比较16×16、64×64、256×256的历史CPP COT来源范围，使用同一运动场、同一目标像元。该诊断使用历史CPP产品，不是当前冻结R的预测结果，不代表可部署GHI增益。

- 样本：冻结月度验证清单中，每个日期固定10:00 BJT初始化，要求过去8帧至未来16帧的24个时间键全部属于validation。先确定日期，后检查CPP存在和质量，不按天气、误差、CPP可用性挑日。
- 运动：复用湖南脚本的完整区域C13相位相关，取历史七个相邻帧位移的中位数；原始20通道AGRI中的C13为索引12。两次输运使用完全相同的运动，不能因范围改变重新估计运动。
- 空间：使用原始256×256 AGRI自带grid_static，卫星方位/天顶角与AGRI原始通道逐像元完全一致。牛首(111,124)、王寨(112,126)、米庄(110,128)，对应经纬度与旧16×16站点一致。旧witness网格是不同范围，不能用其局部索引定位完整区域。
- COT：按BJT减8小时读取原始CPP；LAT/LON逐轴映射，坐标最大误差<1e-4度。仅使用有限且位于[0,100]的COT，不将缺测或源域外填为晴空。此产品头没有专门QC字段，数值范围筛选不称完整产品QC。
- 来源域：共同16×16起点(103,118)，64×64起点(79,94)，256×256起点(0,0)。双线性输运要求参与插值的源像元全部有效。
- 输出：保存每个站点3×3的+15至+240分钟参考/预测COT、覆盖状态与站点像元曲线。主解释为来源覆盖率；共同有效像元上的两个输运值理论上应一致，需要数值核对，不能把覆盖变化冒充共同样本精度改善。另报告“源无效时使用历史持平”的完整配对方案，明确它是带fallback的另一套应用规则。
- 指标：站点像元及3×3的有效上游覆盖、恢复来源的数量；相同参考支持上带持平fallback的RMSE/MAE/bias、厚云COT≥30漏报。按目标日期配对重采样给区间。到达时间仅在参考和预测均出现阈值跨越的序列计算，并报告不可计算数。
- 执行：复旦FD-201 CPU；本轮无神经网络训练，无需GPU，不影响现有任务；test/buffer载荷关闭。不调参、不据此重训GHI。
