# 第二篇论文实验计划

日期：2026-09-05。所有收益均为待检验假设；本文件不表示已运行实验。

## B1 主表与四格消融（必须，正文Table 2）

共同任务：湖南四里/竺家，8→16，+15～+240 min。共同SimVP/COT权重冻结，所有头在相同生成AGRI域训练。太阳几何、lead、站点标识在各组一致，不用站点GHI输入。

| ID | 预测AGRI特征 | COT显式统计 | IFS辐射 | 作用 |
|---|---:|---:|---:|---|
| A | 是 | 否 | 否 | 直接站点头基线 |
| AC | 是 | 是 | 否 | COT无IFS增量 |
| AN | 是 | 否 | 是 | IFS无COT增量 |
| ACN | 是 | 是 | 是 | 完整最小拼接方法 |
| N | 否 | 否 | 是 | 校准IFS强参照，单独训练同预算小MLP |
| C | 否 | 是 | 否 | COT瓶颈充分性；对比AC，不当容量匹配主证据 |
| CLIM | 否 | 否 | 否 | 训练期kt climatology，无初始化实测输入 |

统一CNN与MLP结构见FINAL_PROPOSAL。四格缺少的输入槽用标准化零值占位，模型分别训练，统一种子42/43/44。报告总参数和实际活跃参数；占位不等于有效容量完全相同，因此另设A-wide/AN-wide公平容量对照。
优化初版：AdamW，lr候选3e-4/1e-3，weight_decay1e-4，最多50 epochs、patience8；同组同搜索预算，val上选。有效batch初始64，profile后冻结，若OOM仅降microbatch并梯度累积维持有效batch。
主要终点：每站全16 lead RMSE后两站等权平均；辅助MAE/MBE、样本加权总体RMSE、16 lead曲线。各站单独报告，禁止仅总体掩盖负收益。主表附n、种子变异与日期块CI。

## B2 COT归因（必须，正文Table 3）

1. 容量控制：A-wide、AN-wide扩大hidden到与完整模型有效参数接近（±5%，冻结前登记实际数）；同优化搜索预算。对照太弱则不支持COT价值。
2. 同监督控制：ALN使用与R相同的CPP训练样本、mask、损失和训练预算，读取R的冻结倒数层隐特征（global mean后固定非训练正交投影到4维），与a/n/g/l拼接；ACN读取4维物理COT统计。投影种子预注册11/22/33，不训练、不按val选投影，三种投影均报告；只用train统计标准化，全部成本计入预算；两者共享完全相同R，排除“只有ACN看过CPP监督”。若架构不能精确共享则须明确登记，不能声称已完成同监督隔离。
3. 置换：对固定ACN在同lead/太阳高度分层内置换COT，重复20次，报告性能变化，标签不用作分层依据。这是依赖性诊断，存在分布外干预风险，不是物理因果证明，也不能替代重训无COT对照。
4. COT-only C vs AC：判断是否必须保留多光谱残差信息；若C已经相当，优先用更简单读出，不增加模块。

## B3 检索与外推误差传播（必须，正文Fig. 3）

同一target与CPP有效掩膜上报告R(real AGRI)及R(predicted AGRI)的COT MAE/RMSE、log1p误差、厚云偏差与饱和比例，按lead分解。CPP是真实产品参考值而非无误差物理真值；云相/有效性若无可核查编码则暂停检索解释。
下游oracle替换真实未来AGRI或CPP严格单列、带oracle标记，不进主表、不参与选模；冻结模型后的替换带有输入域偏移，不称严格性能上界。
检验预测COT误差与GHI误差关联，只报告相关诊断，不把关联解释成因果机制。无COT目标可用的样本仍可进入GHI主表，只要推理特征和标签有效；不能按未来CPP是否有效删除主表样本。

## B4 条件互补和失败边界（必须，正文Fig. 2/4）

在共同cohort以站点等权MSE计算 I=MSE(A)-MSE(AC)-MSE(AN)+MSE(ACN)。I<0且配对CI排除0才支持超加性；否则只报告分项差。
预注册时效组(0,60]、(60,120]、(120,240] min；云厚度组阈值取训练期有效CPP的三分位数，未来参考CPP只用于事后分层解释，不作推理特征；另报可部署的历史预测COT分层，二者清楚分开。
稳定/转变天气按训练期kt相邻15min绝对差的75分位数冻结。test观测用于分层标签时标为事后天气诊断，不能当预测输入。各组n、覆盖率与失败案例全部报告；晴天多不能淹没转变天气。
典型日：预先规定按valid样本数足够日期中基线误差的中位日/高分位日选择，出图前固定；同一天所有模型均画，缺时刻断线。

## B5 计算与可靠性（必须profile；额外鲁棒性有条件）

共享一次SimVP全场推理，优先只保存站点patch和小型COT统计；场级诊断另外保存固定代表子集，避免12份全256²缓存。16×13×16×16 float32约0.203MiB/站/初始化，仅两站48,310初始化约19.2GiB纯AGRI载荷（不含索引、COT、重复target和文件开销，按实际manifest核算）。
分别计时SimVP、R、patch head、I/O；冷/热cache延迟分别报告。必要时验证pin memory、workers、混合精度，确认数值后启用。先吃满一张卡再开下一张，不按卡数盲目并行。训练头成本不能掩盖首次骨干/COT训练与缓存成本。
可选：COT噪声/缺测敏感性、不同patch大小、第二套晴空模型；仅在核心结论通过且对应疑问存在时启动。排除diffusion、全骨干排行榜、全CPP变量穷举、D+1～D+3。

## 时间、IFS与cohort合同

- 沿用M0 train 2024-04-02～2025-06-30、val 2025-07-01～2025-09-30、test 2025-10-01～2026-06-30；完整8历史+16未来支撑属于同一split。实际文件和sha核验后封存，不从旧状态表推断已通过。
- init=history_end；target=init+k×15min；GHI标签取target-10/-5/0三个区间结束记录平均。kt分母采用M0相同clear-sky区间合同，低太阳高度的非有限比值不静默clip，登记统一QC。
- 主cohort只依赖因果推理特征可用性、统一白天掩膜和完整GHI真值。在训练之前封存；四格同cohort。另报A/AC可用全集作为覆盖附表，不与主表混算。
- IFS必须release≤init；优先相同cycle覆盖全部16 lead。SSRD累计量在同cycle内相邻step差分/秒数；不同cycle不可差分。原生小时平均量给15min条件时，采用覆盖区间重叠权重聚合（在小时内等通量假设），不宣称增加了原生时间分辨率。缺step断缺，不跨缺口插值。
- COT训练仅在train的CPP参考可用子集拟合，范围/缺测/相态QC固定；推理时不用未来CPP掩膜。每个COT特征都来自预测AGRI。

## 统计与决定门

日期配对bootstrap 2,000次，每次同步抽所有模型/两站/种子预测对应target日期的数据，重新计算非线性RMSE。先每种子算终点再平均，种子std单报；多日块(3/7天)作时间相关敏感性。置信区间是固定已训练模型下天气采样不确定性，不等同全部训练不确定性。
C1主要对比预先锁定ACN-AN，AC-A为支持；同监督ACN-ALN用于显式物理归因。正式检验族的多比较使用Holm校正，报告原始与校正p和CI。pilot仅val探索，不报正式显著性。
实际意义门默认相对RMSE至少降低1%（设计阈值，不是预测结果），主要CI方向一致且两个站点均无明显退化；阈值应在打开第二篇test之前冻结。若某站退化>1%，结论限定到站点/条件，不以总体胜出覆盖它。
val只用于选模，全部配置冻结后统一一次test评估。若第一篇已查看相同test，本篇必须披露共享测试集的先前暴露，不能称全新盲测；新近独立日期可作为后续确认，先审计是否具备数据，不虚构。

## 定稿补充合同
- 同监督控制必须成对：AL对AC、ALN对ACN，分别无IFS/有IFS；AL是用四维隐变量替换显式c，A/AN不变。每一投影种子11/22/33均运行同预算的头，对比显式c时报告全部差异，不挑选有利投影。结论仅针对预注册隐特征对照，不声称胜过所有可能隐表示。
- IFS固定同一产品/stream/grid/version合同；候选周期按release_time降序、cycle init_time降序、product_id字典升序确定唯一选择。同周期重复文件若内容哈希不同则FAIL，不能任意选一个。只有覆盖全部目标区间的周期才可选。
- 几何通道为cosSOZ、cosRAA（无量纲）与day_mask（二值）；前两项使用train统计标准化，day_mask保持0/1。13 AGRI使用train期各波段统计，先恢复SimVP输出的物理单位再用R的norm，不能二次归一化。目标太阳几何由站点/像元坐标和target确定。
- C1主要是应用表示对照结论；检索监督、隐变量投影、汇聚算子都影响表示，若无法完全分离则明确称“显式COT统计管线相对预注册同监督表示”的效果，不做普遍物理因果断言。
