# Four-arm cloud-probability input experiment: B1/B2 results

Date: 2026-10-20. Scope: Hunan Sili and Zhujia, frozen monthly validation only. This is a repeated-use validation analysis, not an independent test or deployment result. Test payloads read: **0**.

## Question and comparison

The primary question is whether a frozen cloud-probability score adds value when the GHI head already receives COT. The primary paired contrast is joint COT + cloud score minus COT-only. A negative RMSE difference favors the joint input. The secondary contrast (joint input minus cloud-score-only) is descriptive because the primary criterion was not met.

The four heads used the same 17-slot architecture, initialization within each station/seed, rows, training order, optimizer and 30-epoch budget. Only COT and cloud-probability input slots changed. The classifier is frozen and retains its archived solar-geometry version; this is not a corrected-geometry classifier experiment. Its score is an input feature, not calibrated cloud fraction, optical transmittance or a physical mask.

## Overall validation result

| Input arm | Equal-station/equal-seed GHI RMSE (W m⁻²) |
|---|---:|
| AGRI + geometry | 89.485 |
| AGRI + geometry + COT | 88.264 |
| AGRI + geometry + cloud score | 88.186 |
| AGRI + geometry + COT + cloud score | 87.795 |

Primary contrast: joint minus COT-only = **−0.469 W m⁻²** (0.531% lower point RMSE), with a paired two-day BJT date-block 95% CI of **[−1.007, +0.047] W m⁻²** (relative reduction CI **[−0.050%, +1.217%]**). All three seed-averaged differences are negative, but the Sili station mean is +0.074 W m⁻² while Zhujia is −1.012 W m⁻². The frozen rule therefore returns **C1 unsupported**: the date-block interval crosses zero and the both-stations non-degradation condition fails.

The secondary joint-minus-cloud-only contrast is **−0.391 W m⁻²** (0.444%) with CI **[−2.273, +1.209] W m⁻²**; it is also inconclusive and remains descriptive. COT-only versus AGRI-only is −1.222 W m⁻² (1.365%; CI [−3.645, +0.725]); cloud-score-only versus AGRI-only is −1.299 W m⁻² (1.452%; CI [−2.373, −0.423]); the joint arm versus AGRI-only is −1.690 W m⁻² (1.889%; CI [−4.340, +0.457]). These contrasts do not replace the primary C1 test. In particular, the cloud-only point/interval is exploratory on this reused validation set and does not establish an independent classifier benefit.

Metrics were independently recomputed in FP64 from all 4,226 saved validation predictions (Sili 1,999; Zhujia 2,227), first within each station/seed and then averaged equally across the two stations and three seeds. The paired bootstrap resampled the same 26 frozen two-day BJT date blocks for every arm, station and seed, 2,000 replicates, seed 20261020. The all-validation C1/C2 intervals exactly reproduce `score_summary_fp64.json`.

CPP COT and CLP are co-produced retrieval references, not independent truth. Strata use the station-centre pixel `[8,8]`, with no patch mean. ## High-irradiance diagnostic

For the pre-specified observed interval-mean GHI threshold of 800 W m⁻², there are 219 unique validation rows (Sili 124; Zhujia 95), or 657 paired station/seed predictions. Equal-station/equal-seed RMSE is 168.054 W m⁻² for COT-only and 166.543 W m⁻² for COT + cloud score (Δ **−1.511 W m⁻²**); the 95% two-day block CI is **[−5.500, +2.032] W m⁻²**, so the subset does not establish a reliable gain. MAE changes from 135.800 to 133.546 W m⁻², and MBE from −131.195 to −129.869 W m⁻². Across the 657 paired predictions, total squared error falls by 1.57%; 399 pairs have lower squared error and 258 have higher squared error with the joint input. This is a small, selected-by-observed-outcome diagnostic subset of the same validation set, not an independent high-irradiance result.

For stratified intervals, draws were sampled from the full 26-block validation list; a draw was rejected only when a station/seed had zero rows in that stratum. The reported “shared-support blocks” count denotes blocks containing the stratum at both stations, not the number of blocks sampled. Intervals are pointwise percentile intervals without multiplicity adjustment.

## Interpretation and next decision

The four-arm experiment does **not** establish that cloud probability adds a reliable GHI improvement on top of COT. It does show a small favorable overall point estimate and a heterogeneous reference-stratified pattern: the thick-COT subgroup is promising, while the thin-COT subgroup worsens. The classifier-only arm is lower than the AGRI-only arm in this validation analysis, but that is exploratory and is not a substitute for the primary COT-plus-cloud contrast.

Per the frozen plan, do **not** start the binary-mask B3 follow-up or add seeds, tune thresholds, retrain the classifier, or make a forecast-chain claim. A future follow-up would need an independently frozen evaluation and should pre-specify the thick-cloud hypothesis; it must preserve the classifier-geometry caveat or retrain/revalidate that classifier under corrected geometry as a separate factor.
