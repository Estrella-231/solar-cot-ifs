# COT外推结果的文献口径对照

日期：2026-10-14（BJT）。用途：完成主计划T22的文献可比性说明。该表用于限定解释范围，不构成同数据集的模型排名。

| 维度 | 本项目：湖南SimVP→冻结R | Cloud-FNO（Zhang et al., 2026） | 可比性判断 |
|---|---|---|---|
| 科学对象 | 单一COT场的短临外推；SimVP先预测AGRI，再由冻结R反演COT | 多任务预测CLP、CTH、CER、COT；FNO并采用自回归策略 | 两者都评价未来COT，但输出任务和预测链不同 |
| 卫星/参考 | FY-4B AGRI及新月度R；当前验证仅CPP共同有效支持。CPP COT是检索参考，不是独立真值 | Himawari-8/AHI全天CPP产品训练与测试；另以MODIS官方产品作第三方基准 | 传感器、检索链和参考产品不同 |
| 时空覆盖 | 湖南两站周边16×16像元，15分钟输入/目标序列；主指标3×3站点邻域 | 全天产品覆盖80°–200°E、60°S–60°N，约5 km、30分钟；训练2016年3–12月，2017年测试 | 区域尺度和空间支持不可直接对等 |
| 预报范围/步长 | +15至+240分钟，16个lead；首轮验证CPP共同支持仅8个目标日期 | 0–6小时、逐小时展示/评估，独立2017测试集 | 本项目短一半、采样更密，但日期支持很小 |
| COT误差主报告 | 物理COT单位；逐lead、先站点等权再lead等权；SimVP→R RMSE 25.538，持续性R 28.252，差−2.714；1日日期块95% CI [−6.476, 0.493] | 独立测试集六小时平均RMSE 9.01；在MODIS基准上的COT RMSE 12.64（Cloud-SimVP 17.02，真实全天CPP产品11.84） | 数值仅作量级背景。9.01与12.64是不同评价部分/参考口径，也不能与本项目3×3站点局地RMSE直接排名 |
| 空间结构指标 | 训练参考尺度归一化log1p(COT)的11×11 SSIM：SimVP→R 0.2356、持续性0.2468；完整有效支持仅占名义窗口24.8% | 6小时测试集平均COT SSIM 0.63；MODIS对照表未报告同定义SSIM | 尺度变换、窗口、范围和支持都不同，不能用0.63与0.236作高低排名 |
| 厚云/事件 | 本项目预先固定COT≥30；3×3 CSI 0.082，持续性0.189 | 文中案例讨论厚云使用COT>10；未报告同阈值总体CSI/FAR | 阈值和统计口径不同，无法数值比较 |
| 统计支持 | 两站、8个CPP支持目标日期；日期块CI跨0。窗口有重叠，结果为验证诊断 | 独立年度测试集；论文另报告按lead和MODIS基准评价 | 本项目目前不能据此声称稳定优势，也不能与其独立测试泛化强度等同 |

## 解读

当前结果显示，SimVP→R在RMSE点估计上比持续性好2.714个COT单位，但日期块区间跨0；厚云CSI和训练尺度SSIM均未优于持续性。因此，本轮证据不支持“湖南短临COT外推已达到Cloud-FNO水平”，也不支持稳定优于持续性。Cloud-FNO的9.01是其独立测试集上的0–6小时平均值，12.64则来自MODIS官方产品基准评价；两者不能混为一个数字。由于我们的站点邻域、FY-4B/CPP参考、15分钟时效、只有8个共同支持日期，与其大范围AHI/第三方MODIS评估均不同，跨研究差异同时包含产品、区域、支持和采样效应。

对本项目有用的结论是评价设计而非追求数值对齐：保留物理单位逐lead误差、图像结构指标、厚云事件和独立参考验证；扩大季节/日期支持后，再判断外推方法是否接近该文报告的短临云物理属性预报能力。后续若补入输运基线，必须先形成相同目标键和CPP支持的bank；不得用只覆盖成功输运像元的子集与全域指标作优劣比较。

## 2026-10-14 主文献来源复核

已在出版社Wiley/AGU论文页核对：Cloud-FNO论文报告的是AHI全天CPP产品上的0–6 h多任务预报，独立测试COT平均RMSE=9.01；研究网格约5 km/30 min、经度80°–200°E/纬度60°S–60°N，训练2016年3–12月、测试2017年。论文还单独用2017年MODIS官方产品做第三方基准，表1的COT RMSE为Cloud-FNO 12.64、Cloud-SimVP 17.02、真实全天产品11.84。来源：[Wiley/AGU article](https://agupubs.onlinelibrary.wiley.com/doi/10.1029/2025GL119553)。

与本项目比较时只能作为评价设计/量级背景：当前是FY-4B→冻结R的两站局地3×3验证结果，15–240 min，CPP参考只覆盖271窗、8个BJT日期；主RMSE 25.538对28.252（持续性），差−2.714，日期块95%描述性区间[−6.476,+0.493]；厚云CSI 0.082对0.189。Cloud-FNO的9.01是其自身CPP独立测试口径，12.64是MODIS第三方基准口径；两者都不与本项目局地、稀疏CPP验证支持构成直接排名。该核对不改变“不足以声明稳定优于持续性或达到Cloud-FNO水平”的结论，也不触发新训练。
