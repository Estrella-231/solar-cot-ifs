## 数据与核验

从保存的 \`pred_log1p_cot\` 读取monthly-R验证预测，FP64下执行一次 \`expm1\`。用CPP COT参考与mask评价。CLP sidecar中sample ID与预测NPZ逐项相同，station/target键齐全且唯一；COT-mask与CLP共同mask逐元素相等。验证集1,398个站点时次（四里700、竺家698），57个BJT目标日期，2024-04-18至2026-03-02。16×16 patch共有357,888个可能像元，CPP共同有效356,169，覆盖99.52%。验证参考范围0–77.79；预测有效范围0.0005–91.08。test读取数0。

参考CPP及同产品CLP来自检索链，以下量化结果代表产品一致性，不是独立地面COT精度。16×16为站点patch，不代表湖南整幅区域。

## 主要结果

COT无量纲；每站先在共同有效像元池化，主汇总为四里与竺家等权平均。

| 空间支持 | 四里 RMSE / MAE / bias | 竺家 RMSE / MAE / bias | 两站等权 RMSE / MAE / bias | 支持像元 |
|---|---:|---:|---:|---:|
| 中心像元 [8,8] | 8.722 / 4.794 / +0.860 | 8.242 / 3.744 / −0.247 | 8.482 / 4.269 / +0.306 | 1,390 |
| 局地3×3 | 8.794 / 4.885 / +0.811 | 8.249 / 3.735 / −0.253 | 8.522 / 4.310 / +0.279 | 12,510 |
| 站点patch 16×16 | 9.674 / 5.508 / +0.751 | 8.433 / 3.785 / −0.192 | 9.053 / 4.647 / +0.279 | 356,169 |

16×16两站合并像元池化RMSE为9.074，与既有FP64复算记录一致。它和两站等权RMSE 9.053是不同估计量，主汇总采用等权站点数值。

按BJT目标日期进行2,000次成簇bootstrap，patch两站等权RMSE的95%区间为6.563–11.829；局地3×3为6.047–11.191；中心像元为6.011–11.144。该区间反映这份已查看验证cohort的日期抽样不确定性，不构成独立test泛化区间。
