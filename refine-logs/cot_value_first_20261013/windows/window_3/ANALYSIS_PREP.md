## GHI 指标复算与配对统计（T11/T14/T26/T29）

1. 只从已保存的逐样本预测和真值重算；预测、真值、掩膜、样本键都必须一一对应。用 FP64 计算，并独立于训练日志。
2. 主评价使用完全相同的 `(station, init_time, target_time)` 与有效掩膜。每站先按该站全部有效样本计算 RMSE，再对两站 RMSE 作等权平均；不把两站样本直接拼在一起后按样本数加权。
3. 对每个 seed，分别计算预先指定方法对比的“方法1 − 方法2”两站等权 RMSE 差；主估计量为三个 seed 差值的算术平均。负值代表方法1的 RMSE 较低。
4. 日期块 bootstrap：按目标时间的 BJT 日期形成簇；每次对日期簇有放回抽样，并在同一抽样中保留所有方法、seed、站点的配对关系，随后重算完整主估计量。执行 2,000 次，报告 percentile 95% CI；另按计划做连续 2 日块敏感性分析。不得对 MSE 先聚合再开方来代替“RMSE 差值”的区间。
5. 输出样本键一致性、每站/总体覆盖数、NaN/掩膜差异、seed 方向、点估计和区间；任何不一致先阻断，不通过插值或删样本强行对齐。

## COT 评价就绪要求（T21/T22）

- 将网络输出按数据合同逆变换一次到物理无量纲 COT 后评价；不把 log 空间误差与物理空间误差混报。
- 16 个 lead 分别报告 RMSE、MAE、bias；站点像元、局地 3×3、区域空间场分开列示。
- 同时给出 CPP 有效且方法共同有预测的支持、各方法完整可预报覆盖、固定 16-lead 公共支持敏感性。无效/缺测不能填成晴空或零 COT。
- 厚云阈值沿用计划中的 COT≥30；另报告低 COT<0.1。厚云样本不足时只描述，不作显著性结论。峰值与到达时间诊断须防止多峰时逐帧 argmax 跳跃造成虚假轨迹。
- 文献对照必须写清数据源、卫星、区域、分辨率、预测范围、参考真值和掩膜。不同时间范围（例如 0–6 h 与本项目 0–4 h）只能作口径说明，不能直接排名。
