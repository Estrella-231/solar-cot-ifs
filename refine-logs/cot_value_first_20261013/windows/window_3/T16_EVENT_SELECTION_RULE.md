# T16 案例选取规则（误差盲选）

状态：窗口3预注册规则；必须在取得或查看新 GHI 预测误差前冻结。  
日期：2026-10-13（BJT）

## 目标

按计划为两站、四季各选 2 个案例，共 16 个：每站-季节一个“参考云场变化”案例和一个确定性哈希案例。案例选取只依赖时间、数据有效性及参考卫星云场/COT，不读取 GHI 标签数值、GHI 预测、误差、模型排名或图像观感。

## 候选样本资格

候选须属于窗口1/总控冻结的湖南目标日期与站点合同；具有完整且通过有效性审核的参考云场/COT变化序列，并有后续绘图所需的 AGRI、太阳几何和 GHI 配对资料。该资格筛选只检查存在性、时间戳和有效掩膜覆盖，不计算或查看 GHI 值。若上游尚未冻结 target/标签合同，不生成事件列表。

## 每站-季节两个事件

1. **变化事件**：对每个合格候选初始化时刻，使用统一物理单位 COT 的参考区域场，计算连续 15 min 帧间的空间平均绝对变化量，并对合同内 0–240 min 的相邻帧变化取平均：

   `D = mean_k mean_{valid pixels} |COT_ref(k+1) - COT_ref(k)|`。

   valid pixel 集合限定为整个序列中按参考产品质量标记有效、且候选间采用同一空间范围的像元；缺测不填零。每站、每季选 `D` 最大的合格候选。完全并列时按 `init_time` 升序，再按样本键字典序取首个。

2. **哈希事件**：对同一站-季节全部剩余合格候选，计算 `SHA256("cot_value_first_20261013|station|season|init_time_BJT")`，按十六进制值升序取首个。排序前移除已被变化事件占用的样本键；若该站-季节候选仅一个，则该层只能提供一个事件并明确记录，不跨季节补位。

## 冻结、失败与报告

- event manifest 需保存站点、季节、完整样本键、D 值、哈希值、参考源/有效像元数、选择规则版本及文件 hash；先生成并冻结 manifest，再让绘图/评分脚本访问 GHI 标签值。
- 若参考 COT/云场、有效空间范围或完整 4 h 序列缺失，不用 AGRI 预测误差、GHI 误差或人工挑图替代；记录缺口并等待上游合同/数据。不得用结果较好看的其他时段补位。
- 若上游实际提供的参考云场与本规则的“统一物理单位 COT、同一空间范围、15 min 序列”不兼容，停止生成 manifest，并在窗口3状态中请求总控决定；不自行改指标口径。
- 所选事件是预注册代表性病例，不是性能最好/最坏病例。最好/最坏样例若后续补充，必须单独标记为事后案例。
