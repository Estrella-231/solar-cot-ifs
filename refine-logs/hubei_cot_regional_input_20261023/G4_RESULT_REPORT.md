# 区域来源覆盖已恢复，但当前两条动态路线未超过历史持平

## 回答的问题

冻结同一新区域反演器及既有修正SimVP后，扩大历史COT来源域，是否足以让未来COT超过“云厚不变”？本轮不训练或评价GHI。输入是历史实际AGRI及可计算太阳几何；未来CPP只作评分参考。

## 相同像元上的结果

503个起报、16目标日期，来自既有月度validation；不是独立test，也不代表全年自然频率。站点像元参考有效记录7672条，三方法共同有效7669条，覆盖99.9609%。因此本轮主要差异不是输运源缺失引起的样本变化。

先对每站、每个15分钟时效分别算RMSE，再等权平均：

|未来COT方法|COT RMSE|相对持平的RMSE差|目标日期块95%区间|
|---|---:|---:|---:|
|历史末帧COT持平|10.043|—|—|
|历史全区域C13运动输运|12.070|+2.027|[+0.555,+3.109]|
|SimVP预测AGRI→同一区域R|18.158|+8.115|[+2.532,+12.418]|

三站的输运及SimVP→R均比持平差，没有删站。3×3同样得到10.038/11.969/18.044。结果不支持把这两条路线直接送入新的GHI收益训练，也不能宣称扩大上游域本身解决了预报。

## 厚度与方法限制

共同站点像元中，CPP≥30的1855条厚云记录的汇总RMSE：持平9.358、输运12.367、SimVP→R22.491；这项按厚云记录汇总，并非主表的站点/时效等权均值。全范围均值不能替代此条件误差，厚云漏报与虚警还须从保存像元继续分解。R自己的厚云偏薄、中等云偏厚问题仍然存在。

全局相位相关平移只描述一个平均运动，未包含局地变形或云增长/消散；SimVP图经R后误差较大，但本轮尚未把位置错误、光谱分布偏移、增厚漏报分开，不能仅凭这些分数宣布唯一原因。扩大来源域恢复覆盖，是必要准备，不是精度改善证明。
