# 历史运动可靠性：无需训练的内部筛选

2026-10-23。前一轮区域轨迹候选已按停止条件封存，不重训、不改其外层验证结果。本方案不重复10月22日学习预测与持平50/50事后混合，不沿已暴露外层验证搜索权重。

## 唯一新增机制

固定同一冻结区域R、8张真实历史COT/有效掩膜、原C13运动估计和像元网格。由历史7个相邻帧对计算“一步输运误差”和“一步持平误差”，只根据这些历史误差判断输运可靠性；不学习厚度残差，也不继续整体压低云厚。所有这些帧均不晚于本次初始化。

在未来像元的回溯来源位置，读取历史7对的COT；持平为前一历史帧在同位置的COT，输运为前一帧在来源位置减一个运动步长处的双线性log-COT。与后一历史帧同位置的R-COT比较，计算物理COT平方误差E_P/E_T。至少4对均有效才启用可靠性，否则q=0。固定q=clip((E_P−E_T)/(E_P+1e−6),0,1)，不扫参数。未来输出为(1−q)×原位置末帧COT+q×输运来源COT。两端在物理空间混合，不用CPP或未来R判断q；不引入全图均值/p90特征。

当历史运动没有优于持平、历史不足或未来来源无效时，输出精确保留持平。在共同来源有效时，输出位于持平与输运之间，不能制造两者之外的厚度。这个约束不保证未来正确，也无法解决两端都漏掉云增厚的问题。

## 先执行的内部筛选

只读取原outer-train内select的2840个因果历史/目标键及19个日期，按已有CPP目标掩膜评分。三站中心、同持平/输运共同有效像元；逐记录保存q、历史有效对数、预测和原参考。内部select已用于方法开发，明确为内部筛选，不能称独立验证。原test/buffer和外层val预测载荷本步骤不读；无新模型训练、无GHI标签。

按三站×16个时效RMSE等权、目标日期5000次配对重采样评价。进入下一步前要求：内部相对持平差的区间上界<0、三站均不退化、厚云RMSE不比持平差；同时报告q生效比例和厚云偏差，不能以置0导致的持平等价称为提升。若不通过，就封存，不调上述规则、不在外层验证试权重。内部通过后另行记录一次固定规则外层评价，再按原计划判断是否进入GHI；内部COT成功不等于GHI成功。

该诊断相对既有方案的变化是历史可观测运动误差决定逐像元q，非学习残差、非固定混合，也非用未来参考位置对齐。原输入、参考、日期和运动算法均不改。
