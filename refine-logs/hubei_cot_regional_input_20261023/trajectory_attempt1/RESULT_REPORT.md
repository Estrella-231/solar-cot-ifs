# 区域历史COT轨迹：未来COT改善相对SimVP，但尚未胜过持平

## 回答的问题

扩大到256×256真实历史区域云场，并逐帧回溯上游后，运动加厚度演变能否产生值得继续检验GHI收益的未来COT？本轮没有训练或评价GHI，不能称辐照度收益。CPP为卫星检索参考；外层验证曾用于开发，不是独立测试。

六个模型已完成，同seed两个臂相同结构、初始化规则、训练行序、优化器和预算。完整best/last、优化器与调度器均已核对。内部三seed平均物理像元MSE选择repeat_last，选臂文件在新模型外层验证之前冻结；没有因外层full略好而换候选。

## 厚云仍被削弱

CPP参考COT≥30的1855条公共站点记录：持平RMSE9.3583，候选三seed平均RMSE14.5963、bias−12.2638。候选仍明显低估厚云，不能把整体比SimVP好等同于保住了最重要云事件。厚云检出POD/FAR/CSI、准确1/2/3/4小时及小时区间、各站各时效、全部厚度层指标均保存在scores，不按误差筛样。

这支持的解释是：避开预测光谱再反演的误差链，可以明显降低相对SimVP的COT误差；但固定运动及学习修正并未可靠胜过不移动的历史云场。当前证据不能区分运动误差和厚度演变误差的全部贡献，也不能证明COT对GHI无效。

## 已接续的训练内部运动归因

未启动新训练，未用外层val调参。直接在原train内部select的2840对、19日期上，用相同历史R与原CPP，独立SciPy回溯比较持平/固定输运；7617条公共站点记录。该处为合并记录描述性RMSE，不能与上表等站点/等时效主指标直接混排。

持平/输运总体6.7332/7.7655；近零1.7566/1.6607、薄云4.4138/4.2843、中等云10.5995/16.2262、厚云12.0594/9.1328。中等云的输运bias为+13.4982，厚云bias为+1.3895。固定输运并非在所有厚度都无效，训练内部厚云反而更好；不能用外层厚云退化反推所有运动都是错的。

内部中等云的明显高估与外层学习候选厚云的明显低估，是下一项应区分的两种误差，而非继续整体下调厚度的理由。当前还没有同一个学习候选在内部各层的配对输出，不能把这两项直接写成已证实的学习因果机制。运动速度中位0.165像元/15分钟，75%分位2.562、最大7.616；需检查来源与云事件，不依据该分布在外层验证调截断值。
