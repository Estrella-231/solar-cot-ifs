# 新时段退化归因：输入范围、历史COT响应及真实云事件

2026-10-23。承接新时段冻结模型结果；本轮无新训练、选模或阈值调整。逐样本结果保持不变。

## 1. 核心结论

此次三站差异，不能解释成“牛首的COT准、王寨和米庄的COT不准”。核对发现，**新时段评价扩大了起报时刻范围**；全零历史COT及训练后头部映射差异，在王寨、米庄退化中占很大份额。真实云事件同时显示SimVP漏掉增厚或抹平局地结构，但当前只把历史COT送入头，不能把两组差异直接归因于“未来COT反演不准”。

上一轮总控只核验了时间值、键和来源，漏查训练与新评价的起报时刻范围，因而把扩大范围后的分数过早解释为单纯新日期确认。这里更正解释，不删除或改写原分数。

## 2. 输入对齐核查

- HDF UTC=BJT−8h，历史顺序−105、−90、…、0 min，预测+15…+240 min；GHI为以target结束的15分钟均值。新标签原始秒记录、完整一分钟箱及两种聚合实现的复算证据沿用LABEL_REPORT。
- 新输入2021帧重新计算完整256²太阳几何，存储角度/几何最大差3.58e−7；逐站目标几何抽查最大差8.94e−8。
- 牛首、王寨、米庄在16×16中的中心分别(8,6)/(9,8)/(7,10)，全场(111,124)/(112,126)/(110,128)，经纬网格分别吻合32.08/112.04、32.04/112.12、32.12/112.20。不是三个站误用一个像元。
- 通道C01–C06、C09–C15；历史与未来各自沿用冻结train归一化，R使用冻结16通道归一化，COT取log1p。3×3排列、8帧顺序与训练代码一致。
- 同一A100/原精度重建新时段9个有COT头的全部预测，最大差为0；不是只在旧验证张量上重放。此前旧验证18个两组头重放也已通过。
- 历史COT有效条件为day_mask>0.5且cosSOZ>cos80；不满足条件的标准化输入置0，是缺效信息，不代表真实晴空COT=0。

这些检查没有发现8小时错误、站点像元错位、通道颠倒或归一化误用。它们不等于原始站点仪器、采样时间或R绝对精度的独立认证。

## 3. 发现的范围差异是实质问题

原头部实际F_fit/F_select/val所有起报均在09:45—15:30，训练及验证中没有8帧COT全部无效的记录。新代码select_inputs.py只要求历史卫星完整、目标标签有效且目标白天，未继承原起报范围；最早纳入03:00起报。目标白天不等于输入历史处于原训练域。

|站点|新样本落在原起报范围外|8帧COT全无效|原训练全无效记录|
|---|---:|---:|---:|
|牛首|54.35%|2521/12545，20.10%|0/35868|
|王寨|55.05%|2808/13122，21.40%|0/35881|
|米庄|52.81%|2438/12441，19.60%|0/34514|

以净平方误差增量逐记录分解：原起报范围外记录贡献王寨净退化的90.47%、米庄的114.30%；超过100%是因为范围内的改善抵消了部分范围外损失。仅全无效COT子群贡献王寨61.62%、米庄106.88%。子群相互重叠，两个百分比不能相加。这是误差份额分解，不是干预因果比例。

固定按原训练实际09:45—15:30作事后范围诊断，不依赖预测好坏选时刻：

## 4. 为什么三站的分数方向不同

|站点|无COT平均偏差|加COT平均偏差|三seed RMSE变化42/43/44|
|---|---:|---:|---|
|牛首|+16.964|+3.663|−0.489 / −0.712 / −4.569|
|王寨|+4.161|+6.674|+0.170 / −0.835 / +10.810|
|米庄|−0.441|+0.172|−3.170 / +4.972 / +4.077|

牛首在全时段被整体下调约13.30 W/m²，削弱了原高估，但改善并不发生在所有天气：实测低于200及200–500组改善，高于500组反而退化。王寨退化高度依赖seed44，不能称三个种子一致失败；米庄两个种子退化，全天平均偏差虽接近0，逐时波动方向仍不准。均值偏差小不代表RMSE低。

误差恒等式：令e=A−y，d=AC−A，则ΔMSE=mean(2ed)+mean(d²)。牛首两项为−1362.58与+771.03，净−591.55；王寨+121.21与+1029.16，净+1150.38；米庄−235.68与+907.68，净+672.00（W²/m⁴）。王寨、米庄的调整幅度带来的误差没有被足够有效的纠错抵消。

全部分层、全部日期均保存在groups.csv和daily.csv，不以个例替代总体。图：[全样本诊断](figures/all_sample_diagnosis.png)。

## 5. 固定同一个头，仅置零COT：区分直接响应与训练映射

两组分别训练后，即使COT输入全0，权重也已不同；AC−A不是纯推理时的COT加减。

|站点|无COT模型|有COT模型、COT正常|同一有COT模型、COT置标准化0|
|---|---:|---:|---:|
|牛首|153.702|151.779|156.366|
|王寨|163.854|167.236|166.630|
|米庄|164.804|166.764|166.468|

牛首的正常COT相对此置零参照改善4.59 W/m²；王寨及米庄分别退化0.61、0.30。但三站直接差的日期CI都跨0，且置零对原正常输入是分布外干预，不能作为另一个可部署模型成绩或证明某一模块的唯一因果作用。可确认的是：COT确实被头使用（平均绝对直接改变量约35.64/27.77/28.33 W/m²），并非完全被忽略；也可确认原输入全无效时直接改变量严格为0。

因此，王寨、米庄的较大模型间差异，并不主要等于一个坏COT值的即时影响。训练后的映射差异、输入域扩张和随机种子不稳定均需区分。

## 6. 真实云图、COT轨迹及GHI案例

取全时段三站反向差异大的3个不同日期，并补2个白天案例；选择仅用于解释机制，不估计发生频率。7月30日缺真实未来图，保留记录而不伪造；其余4例已完成真实材料图。每图含：实际AGRI、SimVP外推、实际AGRI经冻结R的COT、站点COT时间轨迹、观测与两组GHI及固定头置零曲线。

- **7月17日06:00起报**：[图](figures/case_20260717_0600.png)。8帧历史COT全部无效，AC与同头置零预测完全相同。未来实际云图显示云增厚，站点R-COT由约4–6增至50上下，GHI维持低值；SimVP却未保住该变化，GHI随晴空日变化上升到高值。AC相对A在牛首平均低22.68、王寨高16.15、米庄高2.51 W/m²。牛首因此少错一些，另两站多错一些；**本例差异完全不能归因于输入的有效COT信息，因为没有这种输入。**
- **8月6日07:15起报**：[图](figures/case_20260806_0715.png)。历史仅37.5%的COT位置/时刻有效，实际未来COT先增厚后消散，实测GHI发生强波动；SimVP局地结构与真实图差异明显，两组GHI都过于平滑。AC相对A牛首下调55.78、王寨上调15.15、米庄上调4.14；但固定头直接COT改变仅−12.20/−0.99/−2.11。王寨模型间上调不是本例COT支路直接上调。
- **7月18日13:00起报**：[图](figures/case_20260718_1300.png)。处于原训练起报范围，历史COT有效。三站实际云场和COT相近但各自GHI头修正不同，米庄AC相对A进一步下调并扩大低估；王寨部分时段上调加重高估，牛首部分时段上调减轻低估。说明不仅是早晨缺效COT问题，正常白天的纠错方向也未稳定学好。SimVP后期的局地云纹理被抹平，仍是共同输入限制，不足以单独解释AC−A。
- **7月15日06:45起报**：[图](figures/case_20260715_0645.png)。仅12.5%历史COT有效，作为第二个低太阳高度情景，材料与计算均保留。

COT轨迹只显示该时刻R有效的实际图反演值，灰色是无效而非零云；CPP未参与这些新时段案例，R-COT不能叫独立真值。GHI是15分钟均值，不能与瞬时COT逐点作严格辐射闭合。曲线画三seed均值仅为可读，指标始终逐seed算后平均；缺测保持断线。

## 7. 是否是外推COT不准，还是GHI头利用不好

当前这一组没有“未来COT输入”：用的是8帧真实历史AGRI反演COT，未来AGRI由SimVP提供。故“未来COT反演不准导致退化”不是本实验的直接解释。

实际图显示，历史局地COT不能充分代表4小时后的云：在起报与目标R都有效且目标图可用的诊断子集中，起报COT与目标kt的相关系数从第1小时约−0.64/−0.68/−0.66减弱到第4小时约−0.49/−0.47/−0.44；目标同期R-COT相关性更强。各小时可用样本不同，这只是描述性线索，不能叫COT预报精度或因果证据。

现有证据共同说明：**输入对齐值本身未发现错误，但训练与新评价域不一致；在无效/部分COT及长时效下，GHI头没有可靠退回基线或给出正确修正；SimVP又未稳定保住未来云变化。** 这些是可分别核查的限制，不能把全部问题都推给底图，也不能由本站收益正负判定站点标签有问题。

## 8. 下一步边界

先把“原训练覆盖范围的时间外确认”和“扩大到清晨/傍晚的外域诊断”分开报告，保持原全时段负结果。若要覆盖全天，应事前定义起报/历史COT可用域，并让训练也覆盖该域；这需要另命名的训练方案，不能事后只删掉退化时段。若设计历史COT修正，需保证缺效时确实退回同一基线，不能继续把分别训练的两个头之差当作纯COT响应。已做过的残差探索不能直接重新命名重复。

本轮到此只诊断，不自动启动新训练。同期反演的COT价值仍按其独立实验整理。
