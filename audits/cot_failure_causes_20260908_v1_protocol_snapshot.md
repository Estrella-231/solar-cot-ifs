# COT负收益原因分解：固定只读协议

用户最新要求继续检查加入云物理属性后变差的原因。本轮只分析原8个候选的已存validation预测、所有epoch记录和train/validation小型标签数组，不训练，不改样本/模型/损失，不读test或真实未来图像作为头输入。

1. 核验8组预测SHA和共同pack行/真值；展示两cohort全部候选。选定组合严格沿用既有最低validation两站等权GHI RMSE，不另选模型。
2. 对选定A/AC，在两站、全部16lead及固定clear-sky GHI区间[0,20)、[20,100)、[100,300)、[300,600)、[600,+∞)分解RMSE、MAE、偏差和中心化误差；所有区间保留。恒等式ΔMSE=2mean(e_A·delta)+mean(delta²)，只作已存预测描述，不作物理机制因果证明。
3. 读取全部epoch记录，比较训练目标与验证终点走势、最佳及末epoch和相同LR差异。不得为获得收益延长训练或重选终点。
4. 训练loss为w·(pred_kt−kt)²=w·(pred_GHI−GHI)²/clear²。量化固定clear区间与kt>2、>5、>10、>100的数量和零预测参考损失贡献。零预测参考不是训练模型实际残差/梯度；不得将其占比写成实际训练loss贡献。QC1用原keep和原公式重算权重，原分支一并保留。
5. 结合已完成的同目标R(real)/R(forecast)诊断与代码中的四维COT汇聚，分别标注已证实实现、描述性证据与待检验原因。相关性/偏差分解不能单独证明COT因果失效或源产品错配。

输出另名JSON与工程报告，保留输入SHA、代码SHA和全部分组；不写正式论文收益或显著性结论。
