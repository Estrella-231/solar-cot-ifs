# 新旧湖北导出表的时间与单位核查

2026-10-21，承接用户“不知道，你检查下，应该和之前的数据是一样的”。本计划在本轮物理一致性统计前固定；不修改原文件、已有标签、模型、训练或论文。

1. 比较新表与旧表的三个工作表、17列表头、时间格式、采样间隔，以及旧实际标签代码的输入字段和聚合规则。旧对照选已登记的2026-07-07至07-14工作簿，先验证来源哈希。旧表数值仅选择冻结清单中的train日期；test、buffer及val数值不解码。
2. 对新表全部已有记录，以及旧表允许的train记录，比较两种时间解释：裸时间为北京时间，或裸时间为UTC（转北京时间加8小时）。沿用现有项目NOAA太阳余弦及三站坐标，记录太阳高度小于−6度时GHI>20的数量、全部正读数的幅值中占比。这是8小时时区错配诊断，不用于校准分钟级延迟或调模型成绩。
3. 以原表小时为固定分块，至少50条记录、首末跨度至少50分钟、相邻间隔不超过120秒且累计量不下降的块，比较F列梯形积分（按W/m²解释再除以1e6）与K列日累计增量。只在积分≥0.1 MJ/m²且K增量>0的块计算比值；完整报告剔除原因及0增量块。该检查只检验单位尺度一致性，不能独立证明K列单位、仪器标定或水平安装。
4. 若新旧表格式、昼夜相位和尺度一致，可沿用旧工程的北京时间/W/m²操作口径，明确其为有证据的工程推断。设备采样时刻与平台接收时刻若均无独立字段，必须保持未知，不能由相位一致宣称没有分钟级延迟。
5. 不根据模型误差反推标签时移，不打开旧test/buffer数值，不在本轮构造正式独立确认标签或计算预测成绩。

产物为独立JSON、分小时积分CSV和报告补记，不覆盖初次质量审计。
