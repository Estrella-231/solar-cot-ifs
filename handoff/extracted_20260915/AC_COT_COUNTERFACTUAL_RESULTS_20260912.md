# 固定 AC checkpoint 的 COT 反事实前向结果（2026-09-12）

## 验收范围

PBS `208492.tc6000` 使用一张 A100 完成，核心前向约 52 秒。固定 original-cohort
AC checkpoint（seed 42/43/44，LR=3e-4），在同一 99,849 条湖南 validation 行上仅替换
四维标准化 COT 输入。未训练、未读取 test。三个 seed 的 `original` 前向与既有保存预测
逐值完全一致，最大 `pred_kt` 差和总体 GHI RMSE 差均为 0。

独立 NumPy 审计从保存的逐行反事实预测重算全部 168 个 seed×station×weather×variant
指标行，共检查 672 个标量，最大绝对差 `1.14e-13`。

## 四里全 validation 行

下表为三个 seed 的均值。`ΔRMSE/ΔMAE` 是相对同一 AC checkpoint 原始 COT 前向的
变化，负值代表屏蔽后改善；`Δ预测GHI` 为屏蔽后减去原始前向，正值说明原特征参与了
向下修正。

| 四项全置标准化零 | 165.821 | -0.086 | +0.848 | +11.859 | -2.748 / +2.800 / -0.311 |
| 晴天中位 COT | 169.198 | +3.291 | +4.467 | +21.322 | +2.363 / +4.066 / +3.443 |

| 屏蔽空间标准差 | 165.665 | -0.243 | -0.453 | -0.260 | -0.359 / -0.367 / -0.001 |
| 屏蔽 p90 | 164.369 | **-1.539** | **-2.459** | +6.660 | -1.960 / -1.470 / -1.186 |
| 屏蔽中心像元 | 168.597 | **+2.690** | **+5.566** | -1.469 | +5.890 / +0.617 / +1.563 |

四里全样本中，均值与 p90 是最明确的负向修正来源：移除后预测分别平均上移
11.33 与 6.66 W/m²，且三个 seed 的 RMSE 都改善。空间标准差影响很小。中心像元不是
这组负向修正的来源；移除中心像元后三个 seed 都变差，说明它在当前 AC 内提供了有益信息。

四项同时置零的净 RMSE 几乎不变且 seed 方向不一致，说明四个输入在非线性 MLP 中
存在抵消，不能把单项效应简单相加。

## 对结论的限制

这是 AC 模型内部的输入干预。标准化零表示训练集物理均值，不是物理 COT=0；
`sunny_median` 来自 original-training 的 CLP 晴天行，并按站点×lead计算，不使用 validation
统计或标签。AC 权重是在原 COT 下训练的，因此 `AC(c=0)` 不等价于独立 A checkpoint，
本结果不能把全部 A→AC 差异唯一归因给某个输入。它可以支持的结论是：在固定 AC
checkpoint 内，四里全样本的向下响应主要沿均值和 p90 两维出现，而中心像元总体提供
抵消且有益的响应；预测晴天子集需要保留中心像元，并更适合用晴天条件参考替代极端全零。
